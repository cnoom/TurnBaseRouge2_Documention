## 核心设计理念

- **AP只管数量，EN只管质量**：AP=1是标准出牌消耗，EN是质量旋钮，不存在AP≥2的牌
- **策略前置**：玩家在战前完成构筑，局内由系统自动驱动
- **规则严苛，遗物破局**：基础规则无兜底，遗物通过篡改底层规则创造流派
- **引擎思维**：卡组是一个自动运转的引擎，玩家追求稳定性与爆发力的平衡
- **纯1v1**：每场战斗一个敌人，敌人使用相同自动引擎，卡组顺序循环
