## 核心设计理念

- **策略前置，系统执行**：所有玩家决策发生在战前（卡组构筑 + 排序），战斗完全自动播放
- **构筑即玩法**：核心乐趣来自 STS 式构筑深度（三选一加卡/删卡/遗物/流派），战中零操作
- **完全对称**：玩家与敌人共享同一套战斗机制，差异只来自卡组配置，战斗是"两条时间轴的对撞"
- **即时制的体感**：能量实时恢复，能耗 = 出牌时间成本，双方完全并行可同时出牌
- **确定性**：固定 60 tick/s + 种子 PRNG，相同输入可复现，便于调试与平衡

## 核心战斗一览

```
战前：玩家手动排列抽牌堆顺序（确定性序列）
          ↓
战斗（1v1，实时60tick/s，双方并行）：
   双方各自实时回能
        ↓
   能量够打出"抽牌堆顶牌" → 自动出牌 → 进弃牌堆
        ↓
   抽牌堆空 → 弃牌堆洗乱回抽牌堆 → 循环
        ↓
   一方HP归零 → 战斗结算
```

地图与成长完全参照杀戮尖塔：节点图选路、三选一加卡、商店买卖删卡、遗物规则篡改。
