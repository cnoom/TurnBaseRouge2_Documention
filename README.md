## 核心设计理念

- **AP只管数量，EN只管质量**：AP=1是标准出牌消耗，EN是质量旋钮，能力牌AP=2~3
- **策略前置**：玩家在战前完成构筑，局内由系统自动驱动
- **规则严苛，遗物破局**：基础规则无兜底，遗物通过篡改底层规则创造流派
- **引擎思维**：卡组是一个自动运转的引擎，玩家追求稳定性与爆发力的平衡
- **1vN战斗**：支持多敌人同时作战，敌人使用杀戮尖塔式意图系统预定义动作模式，多敌人按速度降序依次行动
