## 设计理念

- **策略前置**：玩家在战前完成构筑，局内由系统自动驱动
- **规则严苛**：基础规则无兜底，长线深度通过遗物实现规则篡改
- **引擎思维**：卡组是一个自动运转的引擎，玩家追求的是稳定性与爆发力的平衡
