# 局外 Meta（跨局永久进度）

> 跨局保留的永久解锁。★ **首版做轻量**：仅解锁新卡牌/遗物进入三选一与商店池，**无永久数值强化、无 Ascension 难度阶梯**。
> demo 完成后考虑升级为「中等」（加 Ascension）。

---

## 设计目标

- 提供跨局的长期目标（解锁全卡池/全遗物）
- **不破坏局内平衡**：Meta 只扩内容、不掺数值（见《进度与成长规范》§二）
- 首局即可体验全部核心机制——不把流派核心锁在 Meta 后面

---

## 一、首版 Meta 内容（轻量）

### 1.1 解锁对象：仅「内容入池」

| 解锁类型 | 入什么池 | 说明 |
|----------|----------|------|
| 新卡牌 | 三选一池 + 商店卡池 | 解锁后该卡出现在随机抽取范围 |
| 新遗物 | 精英/Boss遗物池 + 商店遗物 | 解锁后该遗物出现在随机抽取范围 |

> ★ 解锁 = 「加入可选池」，不是「直接获得」。玩家仍需在局内通过三选一/商店获取。

### 1.2 不做的内容（首版）

| 不做 | 理由 |
|------|------|
| 永久数值强化（+起始HP/起始金币/+力量） | 破坏局内平衡，违背「Meta不掺数值」原则 |
| Ascension 难度阶梯 | 增加设计负担（20级_modifier），首版聚焦核心循环 |
| 多初始牌组/角色 | 首版单一角色（守望者，见《角色系统》）；多角色作为后续 Meta 解锁内容 |
| 永久卡牌升级 | 卡牌升级是局内手段（休息点），不跨局保留 |

## 二、解锁触发（待细化）

> 首版建议：**通关驱动**（击败最终 Boss 解锁下一批）。

| 触发 | 解锁内容（建议） |
|------|-----------------|
| 首次通关 | 解锁一批普通/稀有卡 + 少量遗物 |
| 第 2 次通关 | 解锁更多稀有/罕见卡 + 流派遗物 |
| 第 3~5 次通关 | 池子逐步补全 |
| 5+ 次通关 | 池子基本完整（进入长尾） |

- 解锁内容应**均匀分布**在各流派，避免某流派内容全靠 Meta 解锁
- 解锁后**立即生效**（下一局即可在池中见到）

---

## 三、与解锁内容的关系

- 解锁的卡牌本体定义在《卡牌数据》，遗物本体在《遗物数据》
- 每张卡/遗物需标记「初始可用 / Meta解锁」状态（数据字段，待数据结构细化时补）
- 首批 23 卡 + 21 遗物中，**大部分应初始可用**（保首局完整体验），仅少量扩展内容靠 Meta 解锁

## 与其他系统的关联

- **依赖**：《进度与成长规范》（Meta 不破坏平衡原则）、《卡牌数据》《遗物数据》（被解锁内容本体）
- **被依赖**：奖励系统/商店系统（解锁内容进入这些池的抽取范围）
