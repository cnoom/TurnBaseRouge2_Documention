## 二、成长节奏（与《数值框架》§四联动）

```
1幕（入门/流派雏形）
  ├── 普通战斗×5~7：加卡建立骨架（普通牌替换基础牌，DPS 32→48）
  ├── 精英×1：首件遗物（流派指向）
  └── Boss：罕见卡（罕见100%）+ 罕见遗物 → 流派核心确立
         ↓ HP 回满进下一幕
2幕（成型/精英考验）
  ├── 更多加卡/删卡/升级 → 牌组精炼到 ~15 张
  ├── 精英×1：第二件遗物（流派深化或补短板）
  └── Boss：流派大成
         ↓ HP 回满进下一幕
3幕（大成/深度对抗）
  ├── 最终精修牌组（删卡到 ~15-20 张高质量牌）
  └── 最终 Boss：深度对抗检验构筑
```

## 三、经济循环（与《数据字典》§六联动）

> 详见《奖励系统》「金币与稀有度数值总表」。此处仅汇总流向。

```
金币来源(~800£/局)
  普通战斗25×15 + 精英50×3 + Boss60×3 + 事件宝箱~95
        ↓
金币去向
  删卡575£(删5张) + 买卡/遗物~225£
```

**删卡是金币核心去向**（575£占收入 72%），保删卡性价比是经济设计的第一原则。

## 四、关键约束

- **HP 跨场保留**（幕内），休息点 30% 恢复 / 升级二选一（见《地图与关卡设计》§四）
- **HP 幕间回满**：Boss 后回满进下一幕
- **牌组「随时可排」**：任何非战斗节点可整理排序，加卡不强制弹排序界面
