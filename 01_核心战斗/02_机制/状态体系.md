# 状态体系

> 本文件从《核心战斗机制》中拆出，包含所有状态效果的详细规则、结算顺序，以及出牌流程的效果插入点定义。

## 状态体系

所有状态均为**层数制**，按回合自然衰减。层数增加加时，乘区类状态**效果不变、延长持续时间**，其余状态按层数线性计算效果。

状态分为**异常**（负面）和**增益**（正面）两大类。

### 状态结算顺序

回合内所有状态的结算遵循固定的阶段顺序，同一阶段内部也有严格的先后次序：

```
阶段A：回合开始
  1. 刷新 AP 至上限
  2. 累加 EN
  3. 护盾衰减 30%
  4. 再生回血（触发后-1层，中毒之前结算；HP≤0则立即死亡，后续不再结算）
  5. 中毒扣血（触发后-1层；若HP≤0则立即死亡，后续不再结算）
  6. 眩晕判定：若眩晕层数≥1，标记本回合跳过行动阶段，眩晕层数-1

阶段B：行动阶段（每张牌依次循环以下步骤；若被眩晕跳过，则阶段B完全跳过，直接进入阶段C）

  ── 抽牌与费用 ──
  1. 抽牌（从抽牌堆顶抽1张）
  2. 冻结判定（抽牌后、费用判定前，立即结算层数消耗——无论后续是否打出，层数已在此时扣除）
  3. 费用判定：检查当前AP/EN是否满足该牌费用
     ├── 满足 → 进入步骤4
     └── 不满足 → 强制断档 → 跳至阶段C
  4. 扣除AP/EN

  ── 卡牌生效 ──
  5. 效果结算（按卡牌效果列表顺序依次执行）
     a. **卡牌伤害效果**：力量修正 → 虚弱乘区 → 易伤乘区 → 护盾吸收 → 扣血
        （★ 仅卡牌伤害走此管道；中毒/灼烧/流血/荆棘等状态伤害为固定值，不走此管道）
     b. 护盾效果：敏捷修正 → 叠加到护盾
     c. 状态效果：施加对应层数（易伤/虚弱/中毒/灼烧/眩晕/冻结/流血/荆棘/再生/锐利）
     d. 治疗效果：回复HP
     e. 属性修正：增减力量/敏捷
     f. ★ 结算期间HP≤0立即死亡，停止后续效果
  6. 受击触发：荆棘等（仅步骤5a造成实际扣血时触发，触发后-1层）
  7. 出牌触发：流血等（行动后扣血，持有者行动后扣自身血，触发后-1层）

  ── 收尾 ──
  8. 锐利消耗（打出攻击牌后，全部层数生效后清零）
  9. 牌入目标堆区（弃牌堆 / 消耗堆 / 本场消失）
  10. 死亡检测（HP≤0则移除单位）
  11. 强制抽1张新牌 → 回到步骤2继续循环

阶段C：回合结束
  1. 灼烧扣血（触发后-1层）
  2. 易伤/虚弱衰减（每回合-1层）
  3. 轮换至对方
```

> **关键澄清**：眩晕仅跳过阶段B（行动阶段），阶段A和阶段C的所有效果**照常结算**。被眩晕的回合，中毒仍会扣血、灼烧仍会扣血、再生仍会回血、易伤/虚弱仍会衰减。

#### 异常 — 乘区状态

| 状态 | 效果 | 衰减 | 结算时机 |
|------|------|------|----------|
| 易伤 | 受到卡牌伤害×1.5 | 每回合-1层 | 受到卡牌伤害时（状态伤害不触发） |
| 虚弱 | 造成卡牌伤害×0.75 | 每回合-1层 | 造成卡牌伤害时（状态伤害不触发） |

#### 异常 — 持续伤害状态

| 状态 | 效果 | 衰减 | 结算时机 |
|------|------|------|----------|
| 中毒 | 回合开始扣（层数）点血 | 触发后-1层 | 阶段A：回合开始 |
| 灼烧 | 回合结束扣（层数×2）点血 | 触发后-1层 | 阶段C：回合结束 |
| 流血 | 持有者行动后扣（层数）点血 | 触发后-1层 | 阶段B：行动后扣血 |

> **持续伤害说明**：中毒、灼烧、流血为固定值伤害，**不受力量/易伤/虚弱任何影响**，也不触发荆棘。

#### 异常 — 控制状态

| 状态 | 效果 | 衰减 | 结算时机 |
|------|------|------|----------|
| 眩晕 | 跳过回合行动阶段（阶段B），回合开始/结束效果照常结算 | 每跳过1回合-1层 | 阶段A：回合开始 |
| 冻结 | 抽到牌时，该牌EN消耗增加（增加量 = 冻结层数×20%，向下取整，最少1点），增加部分仅当前回合有效；无论是否打出都会消耗对应层数 | 触发后减少对应层数 | 阶段B：抽牌后、费用判定前 |

**冻结详细流程：**

```
敌方抽到一张牌
  ↓
结算冻结（无论后续是否打出，层数均在此时消耗）：
  该牌 EN消耗 = 原始EN消耗 + 冻结加成
  （冻结加成 = 冻结层数 × 20%，向下取整，最少1点）
  冻结层数 = 冻结层数 - 冻结加成
  ↓
费用判定：当前 AP/EN 是否满足（含冻结加成后的EN）
  ├── 满足 → 正常打出（按加成后的EN扣除）→ 牌入弃牌堆/消耗堆
  └── 不满足 → 强制断档 → 该牌入弃牌堆，冻结增加的EN消失
  ↓
回合结束后，该牌因冻结增加的EN消耗消失
（弃牌堆中的牌费用恢复原值）
```

**冻结衰减示例：**

| 冻结层数 | EN增加 | 消耗层数 | 剩余层数 |
|----------|--------|----------|----------|
| 1 | 1（向下取整） | 1 | 0 |
| 3 | 1（向下取整） | 1 | 2 |
| 5 | 1（向下取整） | 1 | 4 |
| 10 | 2 | 2 | 8 |
| 15 | 3 | 3 | 12 |

**冻结的策略意义：** 冻结层数在抽牌后立即结算并消耗，与后续费用判定结果无关。低层数时衰减极慢（5层以下每次仅消耗1层），会持续影响多个出牌循环；高层数时衰减加速但仍能制造多轮连续压力。逐步消耗而非一次性引爆，适合"温水煮青蛙"式控制。

**眩晕详细说明：**
- 眩晕在阶段A判定，判定后标记本回合跳过阶段B（行动阶段）
- **照常结算的部分**：再生回血、中毒扣血、护盾衰减、易伤/虚弱衰减、灼烧扣血均在各自阶段正常触发
- **被跳过的部分**：抽牌、冻结判定、费用判定、扣除费用、效果结算、受击触发、出牌触发、锐利消耗、牌入堆区、强制抽牌（即阶段B全部步骤）
- 多层眩晕：每跳过1个行动阶段消耗1层，非一次性移除所有层数
- 眩晕不影响阶段C的回合结束结算，灼烧等效果仍然照常触发

#### 增益 — 反击型

| 状态 | 效果 | 衰减 | 结算时机 |
|------|------|------|----------|
| 荆棘 | 受到攻击后反弹（层数×1）点伤害给攻击者 | 触发后-1层 | 受到攻击伤害后 |

**荆棘说明：** 反弹伤害不受力量/易伤/虚弱影响，为固定值。每次受击仅触发1次，多次受击多次触发。护盾吸收的伤害仍会触发荆棘（受到攻击即触发，不论实际扣血多少）。

#### 增益 — 回复型

| 状态 | 效果 | 衰减 | 结算时机 |
|------|------|------|----------|
| 再生 | 回合开始回复（层数）点生命值 | 触发后-1层 | 阶段A：回合开始（中毒之前） |

**再生说明：** 本质是"反向中毒"，与中毒同在回合开始结算。结算顺序：先再生回血，后中毒扣血。因为HP≤0时立即死亡并停止后续结算，再生在前可在中毒致死前拉回血线。

#### 增益 — 蓄力型

| 状态 | 效果 | 衰减 | 结算时机 |
|------|------|------|----------|
| 锐利 | 下次攻击牌的伤害增加（层数）点 | 可叠加，打出攻击牌后全部消耗 | 打出攻击牌后 |

**锐利说明：** 一次性爆发——打出攻击牌后全部层数生效然后清零。每段攻击都享受全部锐利层数加成，在卡牌打出后（步骤⑧）统一消耗清零。与力量的区别：力量是永久加法修正，锐利是可叠加的蓄力释放。在自动引擎中，锐利不会"空转"——玩家迟早会抽到攻击牌，层数终会消耗。

## 出牌流程与效果插入点

阶段B的细化出牌流程为各类效果提供了明确的**插入时机**。设计新效果（遗物、能力牌等）时，需声明在哪个插入点触发：

```
┌─────────────────────────────────────────────┐
│ ① 抽牌                                      │
│   → 可插入：「抽牌时」效果                    │
├─────────────────────────────────────────────┤
│ ② 冻结结算（层数消耗）                       │
│   → 可插入：「费用修正前」效果                │
│   ★ 无论后续是否打出，层数已在此时扣除          │
├─────────────────────────────────────────────┤
│ ③ 费用判定                                  │
│   → 可插入：「费用判定时」效果                │
│   不满足 → 强制断档 → 阶段C                  │
├─────────────────────────────────────────────┤
│ ④ 扣除AP/EN                                 │
│   → 可插入：「费用扣除后」效果                │
├─────────────────────────────────────────────┤
│ ⑤ 效果结算（按效果列表顺序）                  │
│   ├── 卡牌伤害：力→虚→易→护盾→扣血            │
│   │   → 可插入：「伤害计算前/后」「扣血前/后」 │
│   │   ★ 仅卡牌伤害走此管道；状态伤害为固定值    │
│   ├── 护盾：敏捷修正→叠加                     │
│   │   → 可插入：「获得护盾时」                │
│   ├── 状态：施加层数                          │
│   │   → 可插入：「获得状态时」                │
│   ├── 治疗：回复HP                            │
│   │   → 可插入：「获得治疗时」                │
│   └── 属性修正：增减力量/敏捷                 │
│       → 可插入：「属性变化时」                │
│   ★ HP≤0 立即死亡，停止后续效果               │
├─────────────────────────────────────────────┤
│ ⑥ 受击触发（荆棘等）                         │
│   → 可插入：「受到攻击后」效果                │
├─────────────────────────────────────────────┤
│ ⑦ 出牌触发（流血等）                         │
│   → 可插入：「卡牌打出后」效果                │
├─────────────────────────────────────────────┤
│ ⑧ 锐利消耗                                  │
├─────────────────────────────────────────────┤
│ ⑨ 牌入堆区（弃牌堆/消耗堆/本场消失[虚无]）   │
│   → 可插入：「牌入弃牌堆时」「牌被消耗时」      │
├─────────────────────────────────────────────┤
│ ⑩ 死亡检测 → 移除HP≤0单位                    │
├─────────────────────────────────────────────┤
│ ⑪ 强制抽1张新牌 → 回到②                      │
└─────────────────────────────────────────────┘
```

**设计约定：** 新增效果必须声明触发插入点编号（如"在⑤伤害扣血后触发"）。同一插入点内优先结算角色自身效果，再结算敌方效果。遗物和能力牌的触发规则以此流程为唯一参考。
