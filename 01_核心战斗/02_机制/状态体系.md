# 状态体系

> Buff/Debuff 在即时制卡牌对撞中的规则。
> ★ 核心前提：STS 的状态是**回合制**的（"持续2回合""回合开始获得护甲""回合结束护甲清空"），本游戏是即时制无回合，所有状态机制必须**重新映射到时间轴上**。

---

## 设计目标

- 将 STS 经典状态（虚弱/易伤/力量/毒/护甲等）适配到即时制，保持其策略价值
- 保证状态在"双方自动出牌、玩家不可控出牌时机"下仍有意义
- 维护确定性：状态结算在固定 tick 内进行，可复现

---

## 零、★ 状态统一定义表（单一来源）

> 所有状态的**行为参数在此统一定义**。卡牌数据**只写"施加 N 层 X / 获得 N 护甲"，不重复写行为**。
> 状态具体数值（伤害/层数/倍率）由施加它的卡牌决定；此表只定状态的**行为与叠加规则**。

| 状态 | 类型 | 存续 | 叠加规则 | 行为 | 备注 |
|------|------|------|----------|------|------|
| **护甲 Block** | 防御 | 5s后衰减至0 | 累加数值+刷新时长 | 承伤优先扣减；再打护甲牌刷新5s+叠加数值 | 叠甲流基础 |
| **力量** | 增益 | 永久 | 层数累加 | 每层 +1 **攻击牌**伤害（DoT不吃） | 攻击乘区核心 |
| **敏捷** | 增益 | 永久 | 层数累加 | 每层 +1 **格挡数值**（打护甲牌时，获得的护甲量 += 敏捷层数，如3层敏捷则+3护甲） | 防御乘区核心 |
| **易伤** | debuff | 每层1s | 累加层数（叠加持续时间） | 受到伤害 ×1.5（倍率固定不叠加） | 爆发窗口；层数叠加=时长叠加 |
| **虚弱** | debuff | 每层1s | 累加层数（叠加持续时间） | 造成攻击伤害 ×0.75（倍率固定不叠加） | 软减伤；层数叠加=时长叠加 |
| **回能加速** | 增益 | 每层1s | 累加层数（叠加持续时间） | 回能速率 ×1.5（倍率固定不叠加）；每层持续1逻辑秒，叠加层数=叠加总时长 | STS抽牌映射；层数叠加=时长叠加 |
| **毒** | DoT | **永久** | **累加层数（不掉层）** | 每1s按**总层数**结算真实伤害(无视护甲) | 越拖越痛，生存滚雪球流 |
| **灼烧** | DoT | **触发清零** | 累加层数 | 每0.5s结算1层伤害，**结算后该层消失** | 叠多少层跳多少次，爆发倾泻流 |
| **流血** | 标记 | **永久** | 累加层数（不掉层） | 敌人**受到攻击牌伤害后**，额外造成[层数]点真实伤害 | 仅攻击牌触发；快速多段流核心 |
| **荆棘** | 标记 | **永久** | 累加层数 | 受到**攻击牌伤害**时，反弹[当前层数]点真实伤害，**层数-1**；归零消失 | 仅攻击牌触发（与流血统一）；反伤流核心 |

> **卡牌数据书写约定**：施加状态时只写"施加 N 层毒"或"获得 N 护甲"，行为/间隔一律查本表。

### 叠加规则二元划分（设计原则）

- **固定倍率型**（易伤/虚弱/回能加速）：**倍率固定不叠加，层数累加 = 持续时间累加**（每层1s）。兼顾"可延长窗口"与"倍率不失控"
- **数值/层数型**（力量/护甲/敏捷/DoT）：**累加**（数值会因叠加变强，是价值来源）

## 零.五、★ 三系 DoT 差异化（核心设计）

> 三系 DoT 机制完全不同，覆盖三种战斗节奏，是流派分化的核心。

| DoT | 触发方式 | 衰减 | 流派定位 | 与攻击牌关系 |
|-----|----------|------|----------|-------------|
| **毒** | 时间自动（每1s） | **不衰减**（永久） | 生存+滚雪球，越拖越痛 | 无关，独立跳伤 |
| **灼烧** | 时间自动（每0.5s） | **触发掉层** | 爆发倾泻，快速叠层后跳完 | 无关，独立跳伤 |
| **流血** | **受攻击牌伤害触发** | 不衰减（永久） | 快速多段攻击流，攻击越多触发越多 | **强绑定**，仅攻击牌触发 |

### 流血的触发规则（重要，防循环）
- **仅"攻击牌造成的伤害"触发流血**的额外伤害。
- DoT 跳伤（毒/灼烧）、能力牌触发伤（如荆棘）、穿刺伤**都不触发**流血——避免 DoT 与流血互相触发造成无限循环。
- 流血额外伤害是**真实伤害**（无视护甲），且**不受力量加成**（DoT 不吃力量）。

### 数值示例
- 毒：施加20层 → 之后每1s扣20点，永久（需靠伤害灌死敌人，否则毒会越来越痛）
- 灼烧：施加16层 → 每0.5s扣1点共8s，跳16次后清零（共16点）
- 流血：施加12层 → 每次攻击牌命中额外+12点真实伤害；撕裂3段命中 → 额外12×3=36点

## 一、即时制映射的两大决策（已定）

### 1.1 持续时间单位：**秒**（时间制）

| 维度 | STS（回合制） | 本游戏（即时制） |
|------|--------------|----------------|
| 单位 | 回合数 | **秒** |
| 衰减 | 每回合开始 -1 | **每帧按时间衰减**（如持续 3s，则每帧减少 3/60=0.05s 剩余时间） |
| 结算时机 | 回合开始/结束 | **逐帧检查**，到点移除 |

**理由**：与能量连续回能、出牌节奏统一在时间轴上，最符合即时制直觉且可预测。

### 1.2 Block（护甲）：**时间衰减**（非击穿消失）

| 维度 | STS | 本游戏 |
|------|-----|--------|
| 获取 | 出牌获得，叠加 | 同 |
| 存续 | 到回合结束清空 | **获得后持续 5s（逻辑秒）后自动衰减至 0** |
| 扣减 | 承伤时优先扣护甲 | 同（承伤优先扣护甲） |
| 刷新 | 每回合重置 | 护甲牌再次打出时刷新持续时间（而非清零重算，见下） |

**为何选时间衰减而非击穿消失**：
- 出牌是**自动**的，玩家无法选择"敌人要攻击时才开护甲"
- 若护甲是"直到被打穿"，则护甲牌的价值**完全依赖敌人何时攻击**——自动出牌下极其被动
- 时间衰减让护甲的价值**独立于敌人攻击时机**：打出护甲→获得一段时间的防御窗口，玩家只需保证卡组里有护甲牌在循环即可

**护甲刷新规则（建议）**：再次打出护甲牌时，刷新持续时间并**叠加数值**。例：剩余护甲 5 + 持续 2s，再打一张护甲 +5 的牌 → 护甲变 10，持续时间刷新为满。这样允许"叠甲流"。

## 二、状态结算顺序（与核心战斗机制 §七 联动）

每次伤害结算时，按以下顺序处理（帧内瞬时完成）：

```
出牌触发伤害
    ↓
① 计算基础伤害（卡牌 ATK）
    ↓
② 攻击方修正：施加/检查攻击方 buff（如「力量」+ATK）
    ↓
③ 受击方修正：检查受击方 debuff（如「易伤」+50%伤害、「虚弱」-25%伤害）
    ↓
④ 最终伤害 = ②③ 合成结果
    ↓
⑤ 护甲扣减：最终伤害优先扣 Block，超出部分扣 HP
    ↓
⑥ 结算后触发：「受击后」类效果
    ├─ 若本次伤害来自攻击牌 → 检查目标流血，额外造成[流血层数]真实伤害（层数不减）
    ├─ 若本次伤害来自攻击牌 → 检查受击方荆棘 → 反弹[荆棘当前层数]真实伤害给攻击者，荆棘层数-1
    └─ 其他"受击后"效果
    ↓
⑦ 死亡判定：HP≤0 则战败
```

> 所有步骤在**出牌当帧瞬时完成**（遵循核心机制 §二.3 逻辑帧原则）。
> ★ **不做暴击**：本游戏无暴击机制（伤害确定性输出，仅洗牌随机）。
> ★ **不做命中/闪避**：1v1 下所有攻击默认命中（无命中/闪避牌、无相关状态）。
> **流血 / 荆棘**：均仅"攻击牌伤害"触发（DoT/能力牌/穿刺伤不触发，防循环 + 语义统一），层数处理见各自条目。

## 三、STS 经典状态的即时制映射表

> 具体行为参数见「状态统一定义表」（§零）。本表只标注 STS→本游戏的映射要点。

| 状态 | STS 原型 | 本游戏要点 |
|------|----------|-----------|
| 力量 | 攻击牌伤害+N（回合制永久） | 永久累加，每层+1攻击牌伤害，DoT 不吃 |

## 四、三系 DoT 机制详解

> 三系机制完全不同，详见「状态统一定义表」与「三系 DoT 差异化」（§零、§零.五）。此处给出各自的实现机制。

### 4.1 毒（永久累积型）
```
状态持有：层数（只增不减）
每1逻辑秒：对目标结算 [层数] 点真实伤害（无视护甲）
施加规则：累加层数（施加N层 → 层数 += N）
流派：拖时间+生存，越拖越痛
```

### 4.2 灼烧（爆发倾泻型）
```
状态持有：剩余层数
每0.5逻辑秒：结算 1 层伤害（=单跳伤害），该层消失（层数 -= 1）
施加规则：累加层数；层数归零则状态移除
流派：快速叠层后集中爆发，跳完清零
```

### 4.3 流血（攻击触发型，非传统DoT）
```
状态持有：层数（只增不减）
触发：目标受到「攻击牌伤害」后（见§二结算⑥）
效果：额外造成 [层数] 点真实伤害（无视护甲）
施加规则：累加层数
流派：快速多段攻击流，攻击牌打得越多触发越多
注：DoT跳伤/能力牌伤/穿刺伤不触发流血（防循环）；流血额外伤不受力量加成
```

## 五、抽牌类效果 → 回能加速（已定）

> ★ 已定：STS 的"抽牌"在本游戏**不存在**（无回合、无手牌），统一映射为**回能加速**。

### 5.1 机制（★ 层数=持续时间）

- 施加 buff：**回能速率 ×1.5**（倍率固定，不叠加）；**每层持续 1 逻辑秒，叠加层数 = 叠加总持续时间**。
- 例：施加 4 层回能加速 → 回能 ×1.5 持续 4s；再施加 2 层 → 持续时间刷新为剩余+2 层对应秒数。
- 逐帧按时间消耗层数（每 1s 消耗 1 层），层数归零移除。
- 倍率固定不叠加（防止多源叠加导致回能爆炸）；**只叠持续时间**。
- 实现上：这只是一个修改"回能速率"的状态，落入既有状态体系，无需新机制。

### 5.2 设计意义

- 把 STS 里一个回合制专属概念，干净地归并进已有的"回能"轴。
- "多打牌"≈"短时间内更快地打牌"，语义自洽。
- 层数=持续时间的模型，让"叠加"=延长爆发窗口（而非提升倍率），平衡可控。
- 与能耗节奏联动：回能加速期间，高能耗牌也更容易打出，形成爆发窗口。

## 六、状态施加规则

- **叠加规则**：见「状态统一定义表」（§零）。固定倍率型（易伤/虚弱/回能加速）倍率不叠加、层数累加=时长累加；数值/层数型（力量/护甲/敏捷/DoT）累加。
- **冲突处理**：相反状态（虚弱 vs 力量）**独立共存**，各自结算，不做抵消（简化逻辑、保留策略）。
- **驱散（移除状态）**：由特定卡牌/效果执行（如【净化】）。★ 驱散只针对**牌组里的状态/诅咒牌**（移除淤积的负面牌），**不针对场上已施加的 buff/debuff**（场上状态靠时长自然衰减）。多体扩展时再考虑场上驱散。

## 七、状态数据结构（设计用）

每条状态包含：

| 字段 | 说明 |
|------|------|
| 类型 | buff / debuff / dot / shield |
| 效果 | 具体修正（增伤/减伤/回血/伤害等）及数值 |
| 持续时间 | 秒（永久则标记） |
| 结算方式 | 触发式 / 流式（DoT）/ 持续维持 |
| 叠加规则 | 刷新时长 / 叠加层数 / 不可叠加 |
