# 敌人设计

> 完整前期的敌人集合。敌人使用与玩家相同的自动引擎，卡组始终顺序打出，循环后从头重新开始。敌人的成长/强化设计在卡组内（如增益牌），不存在外部难度递增机制。

## 设计规范

### 敌人引擎规则

| 规则 | 说明 |
|------|------|
| 引擎类型 | 与玩家相同：自动出牌引擎，有AP/EN双轨资源 |
| 卡组循环 | 始终顺序打出，打完一轮后从头重新开始，无限循环 |
| 成长机制 | 内嵌在卡组中（如获得力量、获得荆棘的牌），每轮循环强度递增 |
| AP限制 | 敌方卡牌同样遵循AP=0或AP=1的设计理念 |

### 敌人参数说明

| 参数 | 说明 |
|------|------|
| HP | 生命值 |
| AP | 每回合行动力上限 |
| EN | 每回合能量累加值 |
| 卡组 | 敌方的行为模式脚本，顺序循环 |

### 轮转规则

- 战斗顺序：玩家回合 → 敌方回合（1vN时按编号依次执行）→ 循环
- 玩家默认先手
- 敌方回合内，各敌人独立执行完整的出牌引擎

### 数值校验标准

| 敌人类型 | 目标伤害/回合 | HP范围 | 战斗时长 |
|----------|-------------|--------|----------|
| 普通敌人 | ~9 | 35-65 | 6-8回合 |
| 精英敌人 | ~14 | 100-150 | 8-10回合 |
| Boss | ~18 | 150-250 | 10-12回合 |

> 伤害/回合为原始输出，不含玩家护盾减免。实际HP损失约为此值的50-60%。

## 普通敌人（5种）

### N1 哥布林

| 参数 | 值 |
|------|-----|
| HP | 45 |
| AP/EN | 2 / +1 |
| 卡组 | 6张 |
| 定位 | 速攻型：低费高频，嚎叫逐步增伤 |
| 可组队 | 1v2哥布林 |

**卡组：**

| # | 名称 | AP/EN | 效果 |
|---|------|-------|------|
| 1 | 抓击 | 1/0 | 造成4伤害 |
| 2 | 抓击 | 1/0 | 造成4伤害 |
| 3 | 投石 | 1/1 | 造成7伤害 |
| 4 | 抓击 | 1/0 | 造成4伤害 |
| 5 | 嚎叫 | 1/0 | 获得1层力量 |
| 6 | 抓击 | 1/0 | 造成4伤害 |

**行为模式：**

```
3回合一循环：
回合1：抓击4 → 抓击4         = 8伤害
回合2：投石7 → 抓击4         = 11伤害
回合3：嚎叫(+1力) → 抓击4+1  = 5伤害，力量+1
```

循环2起所有伤害+1，循环3起+2，以此类推。前期温后期烫，考验击杀速度。

### N3 史莱姆

| 参数 | 值 |
|------|-----|
| HP | 50 |
| AP/EN | 2 / +3 |
| 卡组 | 6张 |
| 定位 | 蓄力型：前期叠盾蓄力，后期爆发 |
| 可组队 | 1v1 |

**卡组：**

| # | 名称 | AP/EN | 效果 |
|---|------|-------|------|
| 1 | 分泌 | 1/0 | 获得4护盾 |
| 2 | 分泌 | 1/0 | 获得4护盾 |
| 3 | 弹射 | 1/2 | 造成13伤害 |
| 4 | 分泌 | 1/0 | 获得4护盾 |
| 5 | 酸液 | 1/1 | 造成5伤害，施加1层易伤 |
| 6 | 猛撞 | 1/3 | 造成16伤害 |

**行为模式：**

```
3回合一循环：
回合1：分泌4盾 → 分泌4盾       = 8护盾
回合2：弹射13 → 分泌4盾        = 13伤害，4护盾
回合3：酸液5+1易伤 → 猛撞16    = 21伤害，1层易伤
```

前两回合偏防守，回合3突然爆发21伤害+易伤。易伤使下一循环的弹射和猛撞更痛。应对策略：在回合3前击杀或准备充足护盾。

### N4 蝙蝠

| 参数 | 值 |
|------|-----|
| HP | 35 |
| AP/EN | 3 / +1 |
| 卡组 | 5张 |
| 定位 | 骚扰型：高速叠虚弱，吸血续航 |
| 可组队 | 1v2蝙蝠或蝙蝠+哥布林 |

**卡组：**

| # | 名称 | AP/EN | 效果 |
|---|------|-------|------|
| 1 | 尖啸 | 1/0 | 造成3伤害，施加1层虚弱 |
| 2 | 撕咬 | 1/0 | 造成4伤害 |
| 3 | 撕咬 | 1/0 | 造成4伤害 |
| 4 | 尖啸 | 1/0 | 造成3伤害，施加1层虚弱 |
| 5 | 吸血 | 1/1 | 造成5伤害，回复3HP |

**行为模式：**

```
AP=3，5张牌需~2回合一轮（3+2张），但5不能被3整除，实际5回合一周期：
回合1：尖啸3+1虚 → 撕咬4 → 撕咬4    = 11伤害，1层虚弱
回合2：尖啸3+1虚 → 吸血5+3heal → 尖啸3+1虚 = 11伤害，2层虚弱
回合3：撕咬4 → 撕咬4 → 尖啸3+1虚    = 11伤害，1层虚弱
回合4：吸血5+3heal → 尖啸3+1虚 → 撕咬4  = 12伤害，1层虚弱
回合5：撕咬4 → 尖啸3+1虚 → 吸血5+3heal  = 12伤害，1层虚弱
```

持续叠虚弱削弱玩家输出，吸血拖长战斗。但HP极低（35），应优先击杀。

## 精英敌人（2种）

### E1 哥布林首领

| 参数 | 值 |
|------|-----|
| HP | 120 |
| AP/EN | 3 / +2 |
| 卡组 | 10张 |
| 定位 | 速攻强化型：双战吼持续增伤，号令叠易伤 |

**卡组：**

| # | 名称 | AP/EN | 效果 |
|---|------|-------|------|
| 1 | 战吼 | 1/0 | 获得1层力量 |
| 2 | 抓击 | 1/0 | 造成5伤害 |
| 3 | 抓击 | 1/0 | 造成5伤害 |
| 4 | 投石 | 1/1 | 造成8伤害 |
| 5 | 号令 | 1/1 | 造成6伤害，施加1层易伤 |
| 6 | 抓击 | 1/0 | 造成5伤害 |
| 7 | 投石 | 1/1 | 造成8伤害 |
| 8 | 战吼 | 1/0 | 获得1层力量 |
| 9 | 抓击 | 1/0 | 造成5伤害 |
| 10 | 猛投 | 1/2 | 造成14伤害 |

**行为模式：**

```
~4回合一循环（AP=3，10张需~3.3回合）：
回合1：战吼(+1力) → 抓击5+1 → 抓击5+1  = 12伤害，力量+1
回合2：投石8+1 → 号令6+1+1易伤 → 抓击5+1 = 22伤害，1层易伤
回合3：投石8+1 → 战吼(+1力,力→2) → 抓击5+2  = 17伤害，力量+1(总2)
回合4：猛投14+2 → 战吼...（进入下一循环）
```

双战吼让力量持续增长，号令叠易伤使伤害进一步放大。首回合就打出12伤害，压力从始至终。

回合4：风暴16+1 → 强化(+1力,力→2) → 打击9+2 = 28伤害，力量+1(总2)

循环2（力量=2）：
回合5：打击11 → 屏障10盾 → 缠绕10+1易伤   = 21伤害，10护盾，1层易伤
