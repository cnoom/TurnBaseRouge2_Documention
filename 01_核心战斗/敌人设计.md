# 敌人设计

> 敌人系统采用杀戮尖塔式意图系统：敌人在玩家回合展示下回合要执行的动作，玩家据此制定策略。敌人行为为预定义的首轮+循环模式（非动态 AI），通过 `EnemyActionPattern` 配置。

## 设计规范

### 敌人引擎规则

| 规则 | 说明 |
|------|------|
| 引擎类型 | 杀戮尖塔式意图系统，非卡组引擎 |
| 意图展示 | 玩家回合开始时展示敌人下回合意图，玩家可据此制定策略 |
| 行为模式 | `EnemyActionPattern`：首轮动作列表（`firstCycle`）+ 后续循环动作列表（`repeatCycle`），`repeatCycle` 为空则循环 `firstCycle` |
| 执行频率 | 每个敌人每回合执行一个动作（`EnemyActionData`），该动作可包含多个效果（`BattleEffectBase[]`） |
| 效果复用 | 敌人动作的效果直接复用玩家卡牌的 `BattleEffectBase` 体系，一套效果系统服务两套逻辑 |
| 多敌人支持 | 1vN 架构，多敌人按速度降序依次行动 |

### 敌人参数说明

| 参数 | 属性名 | 说明 |
|------|--------|------|
| HP | `MaxHp` | 生命值 |
| 速度 | `Speed` | 决定多敌人回合中的行动顺序，越高越先行动 |
| 行动力 | `ActionRefresh` | 每回合刷新的行动力上限 |
| 能量 | `EnergyAdd` | 每回合增加的能量值（跨回合累积） |
| 动作模式 | `EnemyActionPattern` | 首轮+后续循环的动作列表 |

### 意图类型

| 意图类型 | 枚举值 | 说明 | UI 图标 |
|----------|--------|------|---------|
| 攻击 | `Attack` | 显示伤害数值 | 攻击图标 |
| 防御 | `Defend` | 显示护盾数值 | 防御图标 |
| 增益 | `Buff` | 显示增益数值（力量、治疗等） | 增益图标 |
| 减益 | `Debuff` | 显示减益数值（状态异常等） | 减益图标 |

### 轮转规则

- 战斗顺序：玩家回合 → 敌方回合（多敌人按速度降序依次行动） → 循环
- 玩家默认先手
- 战斗开始时，所有存活敌人生成首回合意图并展示
- 敌人回合结束时，推进动作指针并生成下一意图展示
- 眩晕状态下的敌人跳过行动，但意图指针不推进

### 效果与意图信息的关联

每个 `BattleEffectBase` 子类可重写 `GetIntentInfo()` 返回意图信息：

| 效果类 | 意图类型 | 数值来源 |
|--------|----------|----------|
| `BaseDamageEffect` | Attack | `damage` |
| `PiercingDamageEffect` | Attack | `damage` |
| `BaseShieldEffect` | Defend | `shield` |
| `AddStatusEffect` | Debuff | `stacks` |
| `HealEffect` | Buff | `healAmount` |
| `AddAttributeEffect` | 无（未实现） | - |

### 数值校验标准

| 敌人类型 | 目标伤害/回合 | HP范围 | 战斗时长 |
|----------|-------------|--------|----------|
| 普通敌人 | ~9 | 35-65 | 6-8回合 |
| 精英敌人 | ~14 | 100-150 | 8-10回合 |
| Boss | ~18 | 150-250 | 10-12回合 |

> 伤害/回合为原始输出，不含玩家护盾减免。实际HP损失约为此值的50-60%。

## 敌人回合执行流程

```
EnemyRoundPhase.OnEnter()
  │
  ├── 按速度降序排列存活敌人
  ├── 遍历每个敌人 → EnemyActionExecutor
  │     │
  │     ├── 1. 护盾衰减 50%
  │     ├── 2. 状态结算（中毒扣血、眩晕判定）
  │     ├── 3. 回合开始被动触发
  │     ├── 4. 眩晕则跳过
  │     ├── 5. 执行当前意图动作效果
  │     │     ├── 发布 CardPlay 动画事件
  │     │     ├── 遍历 effects → Resolve 目标 → Execute
  │     │     └── 收集并发布动画事件 (Damage/Heal/BuffChange)
  │     ├── 6. 卡牌打出被动触发
  │     ├── 7. 流血触发
  │     ├── 8. 回合结束状态结算
  │     ├── 9. 回合结束被动触发
  │     ├── 10. AdvanceIndex() + GenerateNextIntent() → 发布下一意图展示事件
  │     └── 11. 死亡检测
  │
  └── 当前敌人完成 → 检查战斗是否结束 → 下一个敌人
```

## 配置数据结构

### 配置文件

- **配置表类**：`EnemyActionConfig : ConfigTable<int, EnemyActionConfigData>`
- **配置文件**：`Assets/Res/Configs/EnemyActionConfig.json`
- **数据项**：`EnemyActionConfigData`（id + name + actionPattern）

### 数据结构说明

```
EnemyActionConfigData
├── id: int                          // 敌人ID
├── name: string                     // 敌人名称
└── actionPattern: EnemyActionPattern
    ├── firstCycle: EnemyActionData[]   // 首轮动作列表
    └── repeatCycle: EnemyActionData[]  // 后续循环动作列表（为空则循环首轮）

EnemyActionData
├── name: string                // 动作名称（如"抓击"、"投石"）
├── intentType: EnemyIntentType // 意图类型（Attack/Defend/Buff/Debuff）
├── intentDesc: string          // 意图描述文字（如"造成8伤害"）
├── animationState: int         // 角色动画状态
├── animationIndex: int         // 动画索引
└── effects: BattleEffectBase[] // 效果列表（多态序列化）
```

## 普通敌人（已配置）

### N1 哥布林（ID=1）

**动作模式：**

**首轮（firstCycle）：**

| # | 名称 | 意图类型 | 效果 |
|---|------|----------|------|
| 1 | 抓击 | 攻击 | 造成8伤害 |
| 2 | 抓击 | 攻击 | 造成8伤害 |

**后续循环（repeatCycle）：**

| # | 名称 | 意图类型 | 效果 |
|---|------|----------|------|
| 1 | 投石 | 攻击 | 造成11伤害 |
| 2 | 嚎叫 | 增益 | 获得1层力量 |
| 3 | 抓击 | 攻击 | 造成4伤害 |

**行为模式：**

```
首轮：
  回合1：抓击8               = 8伤害
  回合2：抓击8               = 8伤害

循环1起（每3回合一循环）：
  回合3：投石11              = 11伤害
  回合4：嚎叫(+1力量)        = 增益，力量+1
  回合5：抓击4(+力量修正)    = 4+力量 伤害
```

首回合两次高伤害抓击形成压力，后续循环中嚎叫逐步增伤。力量每循环+1，使投石和抓击伤害逐步提升。

### N2 骷髅兵（ID=2）

**动作模式：**

**首轮（firstCycle）：**

| # | 名称 | 意图类型 | 效果 |
|---|------|----------|------|
| 1 | 骨击 | 攻击 | 造成5伤害 |
| 2 | 举盾 | 防御 | 获得6护盾 |

**后续循环（repeatCycle）：**

| # | 名称 | 意图类型 | 效果 |
|---|------|----------|------|
| 1 | 骨击 | 攻击 | 造成5伤害 |
| 2 | 骨击 | 攻击 | 造成8伤害 |
| 3 | 举盾 | 防御 | 获得6护盾 |
| 4 | 骨矛 | 攻击 | 造成12伤害 |

**行为模式：**

```
首轮：
  回合1：骨击5               = 5伤害
  回合2：举盾6盾             = 6护盾

循环1起（每4回合一循环）：
  回合3：骨击5               = 5伤害
  回合4：骨击8               = 8伤害
  回合5：举盾6盾             = 6护盾
  回合6：骨矛12              = 12伤害（爆发）
```

攻防交替，骨矛回合爆发。玩家需要预判骨矛回合并准备护盾。首轮相对温和，让玩家有时间建立节奏。

## 系统架构

### 核心类关系

```
EnemyCharacterRuntime : BattleCharacterRuntime
├── IntentRuntime: EnemyIntentRuntime     // 意图运行时（指针循环管理）
│     ├── _pattern: EnemyActionPattern    // 动作模式
│     ├── _currentActionIndex             // 当前动作指针
│     ├── _isFirstCycle                   // 是否首轮
│     ├── GenerateNextIntent()            // 生成下回合意图（不推进指针）
│     ├── ExecuteCurrentAction()          // 执行当前意图并推进指针
│     └── AdvanceIndex()                  // 推进指针
├── StatusEffects: StatusEffectManager    // 状态异常管理
├── PassiveAbilities: PassiveAbilityManager // 被动能力管理
├── HP / 护盾 / 力量 / 敏捷 / 速度
└── 默认动作模式（未配置时每回合5伤害）
```

### 配置层

```
EnemyActionConfig.json → EnemyActionConfig : ConfigTable<int, EnemyActionConfigData>
  └── EnemyActionConfigData (id + name + actionPattern)
        └── EnemyActionPattern (firstCycle + repeatCycle)
              └── EnemyActionData (name + intentType + intentDesc + effects[])
```

### 服务层

| 类 | 职责 |
|----|------|
| `EnemyRoundPhase` | 敌人回合阶段管理，按速度排序后为每个敌人创建执行器 |
| `EnemyActionExecutor` | 单个敌人回合执行（护盾衰减→状态结算→被动→执行意图→回合结束） |
| `EnemyIntentHelper` | 从 `EnemyActionData` 提取意图效果信息（静态工具类） |
| `BattleStartPhase` | 战斗开始时初始化所有敌人意图并展示 |

### UI 展示层

| 类 | 职责 |
|----|------|
| `EnemyIntentUI` | 单个意图图标（Sprite + 数值文字） |
| `EnemyIntentGroup` | 意图图标组管理器（对象池） |
| `EnemyIntentAnimBuilder` | 意图动画构建器（监听 `EnemyIntent` 事件） |
| `EnemyIntentUpdateCommand` | 意图更新命令（回收旧意图→添加新意图） |
