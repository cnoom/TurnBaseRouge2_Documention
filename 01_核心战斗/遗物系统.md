# 遗物系统

> 遗物是"篡改底层规则"的局内获取物。底层战斗规则封闭且严苛，遗物是唯一的破口，为卡组构筑提供流派方向。

## 设计规范

### 核心定位

- **规则篡改型**：遗物不提供"多一张牌"式的数值叠加，而是改变引擎的运转方式
- **纯被动触发**：战斗全自动驱动，遗物不能引入战斗中的主动决策
- **单局获取**：每次新游戏从零开始获取，局外不保留
- **流派锚点**：遗物指明构筑方向，卡牌围绕遗物展开

### 设计约束

| 约束 | 说明 |
|------|------|
| 不引入战斗内选择 | 遗物效果自动触发，不需要玩家在战斗中做决策 |
| 不复制卡牌效果 | 遗物做卡牌做不到的事（改规则），而非重复卡牌功能 |
| 效果可量化 | 每件遗物的收益可估算，便于数值校验 |
| 不堆叠 | 同名遗物不重复获取，效果不叠加 |

### 稀有度

| 稀有度 | 获取方式 | 设计定位 |
|--------|---------|---------|
| 普通 | 商店、普通战斗奖励、事件 | 小幅规则修改，适配性广 |
| 稀有 | 精英战斗奖励、高级商店、特殊事件 | 显著规则修改，明确流派指向 |

### 触发时机

遗物效果必须在以下已有时机点触发，不创造新的时机：

| 时机 | 说明 | 示例 |
|------|------|------|
| 战斗开始 | 战斗初始化时 | 起手获得增益 |
| 回合开始 | 阶段A，AP/EN刷新、状态结算前 | 修改AP/EN回复量 |
| 出牌时 | 阶段B，卡牌打出时 | 消耗牌额外收益 |
| 受击时 | 受到伤害/护盾吸收后 | 受伤触发效果 |
| 断档时 | 费用不满足、回合结束前 | 断档补偿 |
| 回合结束 | 阶段C，状态结算后 | 回合结束触发 |
| 战斗结束 | 胜利时 | 战后收益 |

### 可篡改的规则维度

| 维度 | 底层规则 | 遗物篡改方向 |
|------|---------|-------------|
| 断档 | 费用不满足→回合结束 | 断档时获得补偿 |
| AP | 每回合刷新至上限 | AP上限变化、AP转化 |
| EN | 每回合+3，跨回合保留 | EN回复量、EN溢出 |
| 护盾 | 每回合衰减30% | 衰减率、护盾转化 |
| 卡组流转 | 首轮顺序/后续随机 | 抽牌逻辑改变 |
| 状态 | 各状态固定衰减规则 | 衰减率、触发方式 |
| 废卡 | 洗入后按引擎运转 | 废卡交互 |
| 消耗 | [消耗]牌进入消耗堆 | 消耗牌额外收益、回收 |

## 普通遗物（6件）

### R1 余烬护符

| 属性 | 值 |
|------|-----|
| 稀有度 | 普通 |
| 触发时机 | 回合开始 |
| 效果 | 每回合AP上限+1（即4AP而非3AP），EN增长-1（即每回合EN+2而非+3） |

**设计思路：** 以EN积累速度换取AP出牌频率。+1AP=+33%出牌权，-1EN=EN积蓄节奏放缓。适合低费牌（0EN/1EN）为主的快节奏构筑，但高EN牌（2+EN）的使用窗口被拉长。

**数值校验：**
- 初始卡组（全1/1牌）：4AP+2EN=恰好出2张1/1牌（vs 原3AP+3EN=出3张），首回合收益略降
- 含0EN牌卡组：4AP+2EN=出2张0EN+2张1EN=4张牌，33%频率提升
- 高EN牌（如2/3终结一击）：需积蓄2回合才能凑够6EN，原需3回合凑9EN，窗口并未缩短
- 遗物价值取决于卡组中0-1EN牌占比，是中后期构筑方向锚点

---

### R2 能量晶体

| 属性 | 值 |
|------|-----|
| 稀有度 | 普通 |
| 触发时机 | 战斗开始 |
| 效果 | 战斗开始时，EN+3（首回合EN=6而非3） |

**设计思路：** 首回合EN前置爆发。让第一回合就能打出2EN及以上费用的卡牌，抢占开局节奏。后续回合EN回复量不变（每回合+3），首回合优势随时间稀释。

**数值校验：**
- 初始卡组（全1/1牌）：首回合3AP+6EN=出3张1/1，与无遗物一致，无实质提升
- 含0EN牌卡组：释放的EN可投入高阶牌，首回合出牌组合更灵活
- 对首回合需要高EN爆发（如开场打2/3终结一击）的构筑价值最高

---

### R3 铁匠锤

| 属性 | 值 |
|------|-----|
| 稀有度 | 普通 |
| 触发时机 | 出牌时 |
| 效果 | 每打出一张[消耗]牌，获得1层力量（不含[虚无]废卡） |

**设计思路：** 消耗流核心。消耗牌削减卡组厚度的代价换回永久力量成长。配合战吼、肾上腺素等消耗牌，卡组越打越薄但越打越猛。注意废卡为[虚无]标签（非[消耗]），不触发此效果。

**数值校验：** 卡组含2-3张消耗牌→获得2-3层力量=每张攻击牌+2~3伤害。中后期消耗牌积累后收益递增。10回合战斗中若打出5张消耗牌=+5力量=每张攻击牌+5伤害，显著提升终结能力。

---

### R4 剑鞘

| 属性 | 值 |
|------|-----|
| 稀有度 | 普通 |
| 触发时机 | 断档时 |
| 效果 | 断档时，每剩余1点AP获得2护盾 |

**设计思路：** 断档是核心惩罚机制，剑鞘将其转化为部分防御收益。3AP断档在第1张牌就断=6护盾，在第2张牌断=4护盾。不消除断档的负面性，但将伤害压力转化为护盾缓冲。

**数值校验：** 典型场景：2AP断档→4护盾，约等于一张1/0格挡的80%效率。作为被动触发、无需条件满足，收益合理。

---

### R5 废铁护腕

| 属性 | 值 |
|------|-----|
| 稀有度 | 普通 |
| 触发时机 | 出牌时 |
| 效果 | 抽到废卡时，获得1EN（替代原有的无收益惩罚） |

**设计思路：** 废卡交互转换。正常情况下废卡（淤塞/腐蚀/伤痛）是纯惩罚，废铁护腕将其转化为EN收益——每张废卡反而成为加速EN积累的"免费电池"。废卡仍为[虚无]标签（打出后消失），不污染后续循环。

**数值校验：**
- 淤塞（1/0 [虚无]）：原=消耗1AP无收益 → 废铁护腕=消耗1AP+1EN（净赚EN节奏）
- 腐蚀（0/1 [虚无]）：原=消耗1EN无收益 → 废铁护腕=0AP净支出（免费EN转移）
- 伤痛（0/0 [虚无]）：原=自伤6HP → 废铁护腕=自伤6HP+1EN（生存换资源）
- 收益取决于战斗中废卡数量，废卡生成类敌人/事件越多，价值越高

---

### R6 荆棘盾

| 属性 | 值 |
|------|-----|
| 稀有度 | 普通 |
| 触发时机 | 回合开始 |
| 效果 | 回合开始时，获得1层荆棘 |

**设计思路：** 反伤流基石。每回合自动积累1层荆棘，荆棘层数永久保留（不衰减），每层=受到攻击时反弹1点伤害。配合卡牌中的荆棘叠加（铁壁）和冰甲，可快速堆叠到10+层。对高频低伤敌人（哥布林、蝙蝠群）压制力极强，对低频高伤敌人（骸骨骑士）效果有限。

**数值校验：**
- 哥布林（每回合2次攻击×10回合）：~10层荆棘触发=~20额外伤害，占哥布林45HP的44%
- 骸骨骑士（每2回合1次攻击）：同10层荆棘仅触发5次=~5额外伤害，效率骤降
- 配合冰甲（受伤+2荆棘）：受击反向加速荆棘积累，形成正反馈循环

## 稀有遗物（4件）

### RR1 不灭之火

| 属性 | 值 |
|------|-----|
| 稀有度 | 稀有 |
| 触发时机 | 断档时 |
| 效果 | 断档时，剩余AP全部转化为EN（下回合可用） |

**设计思路：** 断档的重构。剑鞘是"断档→护盾"的防御路线，不灭之火是"断档→EN蓄力"的进攻路线。3AP断档在第1张=存3EN，第2张=存2EN。断档不再是纯惩罚，而是EN蓄力手段。

**与剑鞘的差异：**
- 剑鞘：即时防御，当回合生效
- 不灭之火：蓄力进攻，下回合爆发

**流派构建：** 配合高EN牌（暴风斩、终结一击），刻意构建"断档→蓄力→爆发"循环。

**数值校验：** 断档存3EN+下回合+3EN=6EN，可支撑1/5终结牌+2张1/0牌。将"断档"从惩罚转为节奏选择。

---

### RR2 凝固水晶

| 属性 | 值 |
|------|-----|
| 稀有度 | 稀有 |
| 触发时机 | 回合开始（护盾衰减结算前） |
| 效果 | 护盾不衰减 |

**设计思路：** 重写护盾规则。正常护盾每回合衰减30%（6回合后残余仅14%），凝固水晶移除衰减，让护盾永久累积。防御型构筑的核心遗物，将"用完即弃"的护盾转化为可堆叠的永久资产。

**数值校验：**
- 无遗物：每回合8护盾，6回合后约净存14护盾（衰减后残余）
- 有遗物：每回合8护盾，6回合后净存48护盾
- 防御量差距3.4倍，与高护盾牌（坚守8、要塞11、神盾20）配合极佳

**风险控制：** 护盾无限累积不会导致无敌——敌人有穿刺（绕护盾直伤）、易伤（放大穿透伤害）、灼烧（无视护盾DOT）等手段。需关注史莱姆、骸骨骑士等高爆发敌人是否需额外调整。

---

### RR3 鲜血圣杯

| 属性 | 值 |
|------|-----|
| 稀有度 | 稀有 |
| 触发时机 | 战斗开始 |
| 效果 | 战斗开始时，失去20HP，获得AP上限+1（每回合4AP而非3AP） |

**设计思路：** 以血换规则，高风险高回报。20HP（初始100HP的20%）=换取33%的永久出牌频率提升。适合追求极致进攻节奏的构筑，与余烬护符（AP+1/EN-1）叠加可达5AP/回合。

**数值校验：**
- 4AP/回合 × 3回合 = 12次出牌（vs 3AP×3=9次），+33%出牌权
- 初始卡组（全1/1）：4AP+3EN=恰好出3张1/1（与无遗物相同，无立即收益），需搭配0EN牌释放AP红利
- 配合治愈牌（6HP回复）、再生光环可缓解血量压力
- 伤痛废卡（自伤6HP）与圣杯的"以血换资源"理念一脉相承

**流派构建：** 配合治愈牌、再生光环，用额外AP弥补生命损失。高频出牌+高频回血形成自循环。

---

### RR4 命运罗盘

| 属性 | 值 |
|------|-----|
| 稀有度 | 稀有 |
| 触发时机 | 回合结束 |
| 效果 | 每回合结束时，若抽牌堆剩余≤3张牌，获得2层锐利 |

**设计思路：** 循环加速流。当卡组即将耗尽（即将洗牌重置）时触发锐利，意味着新一轮循环的首张攻击牌伤害+2。配合消耗牌主动缩减卡组厚度，加速循环频率，让锐利触发更密集。

**数值校验：**
- 10张卡组、3AP/回合：约3.3回合循环一轮，每轮获2锐利=首攻+2伤害，等效+0.6伤害/回合
- 配合[消耗]牌缩减卡组：10张→8张→6张，循环加速至2回合一轮，锐利触发频率翻倍
- 配合蓄力斩（固有+2锐利）：循环结束时额外2锐利，首攻+4伤害，爆发力显著

## 遗物组合与流派

| 流派 | 核心遗物 | 配合卡牌 | 特征 |
|------|---------|---------|------|
| AP加速流 | 余烬护符 | 0EN攻击牌、低费牌 | 以EN换AP频率，快节奏多出牌 |
| 消耗流 | 铁匠锤 | 战吼、肾上腺素 | 消耗牌=力量叠加，卡组越打越薄但越打越猛 |
| 断档防御流 | 剑鞘 | 高EN牌、护盾牌 | 主动断档换护盾，AP压力转防御 |
| 断档蓄力流 | 不灭之火 | 终结一击、暴风斩 | 刻意断档蓄EN，爆发一击 |
| 护盾流 | 凝固水晶 | 坚守、要塞、神盾、磐石 | 护盾永久累积，铜墙铁壁 |
| 反伤流 | 荆棘盾 | 铁壁（荆棘）、冰甲 | 自动反伤，对抗高频敌人 |
| 高频进攻流 | 鲜血圣杯 | 治愈、再生光环、战吼 | 以血换出牌频率 |
| 循环加速流 | 命运罗盘 | 消耗牌、蓄力斩 | 缩减卡组加速循环，每轮爆发 |
| 废卡免疫流 | 废铁护腕 | 伤痛 | 废卡变收益 |

## 获取方式

| 来源 | 遗物池 | 说明 |
|------|--------|------|
| 普通战斗奖励 | 普通 | ~30%概率掉落 |
| 精英战斗奖励 | 普通+稀有 | 100%掉落，稀有概率~40% |
| Boss击杀 | 稀有 | 100%掉落稀有遗物 |
| 商店 | 普通 | 花费金币购买 |
| 事件 | 普通+稀有 | 部分事件可选择遗物 |

> 遗物不重复获取。若所有遗物已获取，不再掉落。

## 数值校验

### 各遗物等效收益估算

| 遗物 | 触发频率 | 单次收益 | 平均收益/回合 | 占HP等效 |
|------|---------|---------|-------------|---------|
| 余烬护符 | 每回合 | +1AP/-1EN | +33%AP/-33%EN | 中 |
| 能量晶体 | 1次/战斗 | 3EN前置 | 首回合加速 | 低 |
| 铁匠锤 | ~2次/战斗 | 1力量 | ~0.7伤害/牌（递增） | 中 |
| 剑鞘 | ~2次/战斗 | 4护盾 | ~1护盾/回合 | 低 |
| 废铁护腕 | 视废卡数量 | 1EN | 依赖场景 | 低-中 |
| 荆棘盾 | 每回合 | 1荆棘 | ~1伤害/回合（受击时） | 中 |
| 不灭之火 | ~2次/战斗 | 2-3EN | ~1.5EN/回合 | 高 |
| 凝固水晶 | 每回合 | 等效+3-5护盾 | ~4护盾/回合 | 高 |
| 鲜血圣杯 | 1次/战斗 | +1AP永久 | +33%出牌权 | 高 |
| 命运罗盘 | ~2次/战斗 | 2锐利 | ~0.6伤害/回合 | 中 |

## 与其他系统的关联

| 关联系统 | 关系 | 说明 |
|----------|------|------|
| 核心战斗机制 | 篡改 | 遗物直接修改底层规则（断档、AP、EN、护盾衰减等） |
| 卡牌设计 | 互赖 | 遗物指明流派方向，卡牌围绕遗物展开 |
| 敌人设计 | 验证 | 敌人的特殊机制（穿刺、易伤、灼烧）是遗物效果的校验手段 |
| 局外系统 | 下游 | 遗物的获取节奏由局外系统决定 |
