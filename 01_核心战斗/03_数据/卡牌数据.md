## 设计基准回顾

| 项 | 值 | 说明 |
|----|----|------|
| 回能 | 8/s逻辑 | 连续浮点累积 |
| 基础牌能耗 | 4 | 0.5s/张 |
| 每费伤害(基础档) | 4（16伤/4费） | 基础牌低于锚点 |
| 每费伤害(普通锚点) | 6（24伤/4费） | 普通牌=DPS锚点 |
| 每费护甲(基础档) | 3（12甲/4费） | 基础牌低于锚点 |
| 每费护甲(普通锚点) | 5（20甲/4费） | 普通牌锚点 |
| 力量 | +1伤害/层（永久） | 仅加攻击牌伤害，DoT不吃 |
| 易伤 | ×1.5（每层1s，叠层=叠时长） | 爆发窗口 |
| 虚弱 | ×0.75（每层1s，叠层=叠时长） | 生存 |
| Block | 5s衰减 | 见《状态体系》 |
| 状态持续 | 3s | debuff基准 |

> **每费伤害档位**：基础4 < 普通锚点6 < 稀有7+或带机制 / 罕见机制质变。
> **能耗=时间铁律**：纯数值牌DPS与能耗无关（恒定），高能耗牌必须靠效果质变。

## 九、★ 卡牌升级规则（休息点强化）

> 来源：休息点二选一——回血 30% **或** 升级 1 张卡（见《地图与关卡设计》§四）。
> ★ 设计原则：**升级幅度 = 提升一档稀有度数值**。基础牌升到普通锚点、普通牌升到稀有档、稀有/罕见牌加附带效果或数值微增。

### 9.1 升级幅度基准

| 原稀有度 | 升级后幅度 | 例子 |
|----------|-----------|------|
| **基础** | → 普通锚点档 | 打击 16伤→24伤；防御 12甲→20甲；重击 40伤→48伤 |
| **普通** | → 稀有档（+4~8 数值 或 加附带效果） | 劈砍 24伤→32伤；格挡 20甲→28甲；淬毒 8层毒→12层毒 |
| **稀有/罕见** | 数值微增 或 附带新效果（不质变） | 战意 4层力量→8层；要害 易伤+12→+16；斩杀 30%阈值→40% |

### 9.2 升级约束

- **状态/诅咒牌不可升级**（负面牌无升级价值）
- **能力牌升级**：优先提升触发效果数值（如战意 4层力量→8层），不加冷却（保持能力牌设计原则）
- **每张牌只能升级一次**（不叠升级）
- 升级后牌名可加"+"后缀（如"打击+"），视觉区分

### 9.3 与其他系统关联

- 升级是**局内成长**的加法出口（与删卡做减法互补）
- 升级不改变稀有度（升级牌+仍是原稀有度，只是数值更强）
- 升级选择是休息点的核心决策：回血保续航 vs 强化主力攻防
