# 普通遗物

> 本文件从《遗物系统》中拆出，包含6件普通遗物的完整数据。设计规范见《遗物设计规范》。

### R1 余烬护符

| 属性 | 值 |
|------|-----|
| 稀有度 | 普通 |
| 触发时机 | 回合开始 |
| 效果 | 每回合AP上限+1（即4AP而非3AP），EN增长-1（即每回合EN+2而非+3） |

**设计思路：** 以EN积累速度换取AP出牌频率。+1AP=+33%出牌权，-1EN=EN积蓄节奏放缓。适合低费牌（0EN/1EN）为主的快节奏构筑，但高EN牌（2+EN）的使用窗口被拉长。

**数值校验：**
- 初始卡组（全1/1牌）：4AP+2EN=恰好出2张1/1牌（vs 原3AP+3EN=出3张），首回合收益略降
- 含0EN牌卡组：4AP+2EN=出2张0EN+2张1EN=4张牌，33%频率提升
- 高EN牌（如2/3终结一击）：需积蓄2回合才能凑够6EN，原需3回合凑9EN，窗口并未缩短
- 遗物价值取决于卡组中0-1EN牌占比，是中后期构筑方向锚点

### R2 能量晶体

| 属性 | 值 |
|------|-----|
| 稀有度 | 普通 |
| 触发时机 | 战斗开始 |
| 效果 | 战斗开始时，EN+3（首回合EN=6而非3） |

**设计思路：** 首回合EN前置爆发。让第一回合就能打出2EN及以上费用的卡牌，抢占开局节奏。后续回合EN回复量不变（每回合+3），首回合优势随时间稀释。

**数值校验：**
- 初始卡组（全1/1牌）：首回合3AP+6EN=出3张1/1，与无遗物一致，无实质提升
- 含0EN牌卡组：释放的EN可投入高阶牌，首回合出牌组合更灵活
- 对首回合需要高EN爆发（如开场打2/3终结一击）的构筑价值最高

### R3 铁匠锤

| 属性 | 值 |
|------|-----|
| 稀有度 | 普通 |
| 触发时机 | 出牌时 |
| 效果 | 每打出一张[消耗]牌，获得1层力量（不含[虚无]废卡） |

**设计思路：** 消耗流核心。消耗牌削减卡组厚度的代价换回永久力量成长。配合战吼、肾上腺素等消耗牌，卡组越打越薄但越打越猛。注意废卡为[虚无]标签（非[消耗]），不触发此效果。

**数值校验：** 卡组含2-3张消耗牌→获得2-3层力量=每张攻击牌+2~3伤害。中后期消耗牌积累后收益递增。10回合战斗中若打出5张消耗牌=+5力量=每张攻击牌+5伤害，显著提升终结能力。

### R4 剑鞘

| 属性 | 值 |
|------|-----|
| 稀有度 | 普通 |
| 触发时机 | 断档时 |
| 效果 | 断档时，每剩余1点AP获得2护盾 |

**设计思路：** 断档是核心惩罚机制，剑鞘将其转化为部分防御收益。3AP断档在第1张牌就断=6护盾，在第2张牌断=4护盾。不消除断档的负面性，但将伤害压力转化为护盾缓冲。

**数值校验：** 典型场景：2AP断档→4护盾，约等于一张1/0格挡的80%效率。作为被动触发、无需条件满足，收益合理。

### R5 废铁护腕

| 属性 | 值 |
|------|-----|
| 稀有度 | 普通 |
| 触发时机 | 出牌时 |
| 效果 | 抽到废卡时，获得1EN（替代原有的无收益惩罚） |

**设计思路：** 废卡交互转换。正常情况下废卡（淤塞/腐蚀/伤痛）是纯惩罚，废铁护腕将其转化为EN收益——每张废卡反而成为加速EN积累的"免费电池"。废卡仍为[虚无]标签（打出后消失），不污染后续循环。

**数值校验：**
- 淤塞（1/0 [虚无]）：原=消耗1AP无收益 → 废铁护腕=消耗1AP+1EN（净赚EN节奏）
- 腐蚀（0/1 [虚无]）：原=消耗1EN无收益 → 废铁护腕=0AP净支出（免费EN转移）
- 伤痛（0/0 [虚无]）：原=自伤6HP → 废铁护腕=自伤6HP+1EN（生存换资源）
- 收益取决于战斗中废卡数量，废卡生成类敌人/事件越多，价值越高

### R6 荆棘盾

| 属性 | 值 |
|------|-----|
| 稀有度 | 普通 |
| 触发时机 | 回合开始 |
| 效果 | 回合开始时，获得1层荆棘 |

**设计思路：** 反伤流基石。每回合自动积累1层荆棘，荆棘层数永久保留（不衰减），每层=受到攻击时反弹1点伤害。配合卡牌中的荆棘叠加（铁壁）和冰甲，可快速堆叠到10+层。对高频低伤敌人（哥布林、蝙蝠群）压制力极强，对低频高伤敌人（骸骨骑士）效果有限。

**数值校验：**
- 哥布林（每回合2次攻击×10回合）：~10层荆棘触发=~20额外伤害，占哥布林45HP的44%
- 骸骨骑士（每2回合1次攻击）：同10层荆棘仅触发5次=~5额外伤害，效率骤降
- 配合冰甲（受伤+2荆棘）：受击反向加速荆棘积累，形成正反馈循环

## 与其他系统的关联

| 关联系统 | 关系 | 说明 |
|----------|------|------|
| 遗物设计规范 | 上游 | 遵循遗物触发时机、稀有度定位、设计约束等规则 |
| 核心战斗机制 | 上游 | 遗物效果篡改底层规则（AP/EN/护盾衰减等） |

| 敌人设计 | 验证 | 敌人机制（穿刺/易伤/多段攻击）是遗物效果的校验手段 |
