# 遗物数据（首批）

> 首批 ~21 件遗物，覆盖各流派与可篡改轴。
> ★ 精简池定位：每件都强且独特，流派指向明确。
> ★ 携带不限；乘区独立避免失控。
> 参数锚点见《数值框架》，机制见《遗物设计规范》。

---

## 设计基准回顾

| 轴 | 基准值 | 遗物可篡改 |
|----|--------|-----------|
| 回能 | 8/s | 增减 |
| 基础能耗 | 4 | 降低特定类 |
| Block | 5s衰减 | 时长/永久 |
| 力量 | +1/层 | 起始/额外 |
| 毒/灼烧/流血 | 三系各异 | 各强化方向 |
| HP | 240 | 最大HP/回复 |

## 五、角色专属遗物（不进通用池）

> 角色开局自带，不在三选一/商店/精英/Boss 掉落池中。详见《角色系统》。

### 【轮回印记】Mark of Cycles（守望者专属）
| 字段 | 值 |
|------|----|
| 稀有度 | 专属（不进池） |
| 类型 | 机制篡改 |
| **效果** | 每打出 **5 张牌**，**回复 8 点能量**（即时注入）。 |
| 篡改轴 | 出牌频率 / 能量 |
| 流派 | 中性。奖励牌组持续滚动——循环越快，触发越频繁，等效"出牌时间打折" |
| 设计意图 | 守望者专属。把"牌组循环"本身变成收益源，与即时制核心机制（卡牌循环+连续回能）深度联动。流派中性，任何构筑都受益。见《角色系统》§三。 |
