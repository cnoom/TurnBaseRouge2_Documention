# 敌人卡组数据（首批原型）

> 首批敌人原型，按幕间曲线从弱到强。
> ★ 对称设计：敌人复用玩家牌为主 + Boss 少量专属牌。
> ★ 牌组不可见（观战式）；敌人牌组有**预设顺序**（设计者排序=首轮行为）。
> 参数锚点见《数值框架》，牌引用《卡牌数据》。

---

## 设计基准回顾

| 项 | 值 |
|----|----|
| 玩家回能 | 8/s（敌人默认对称，可调） |
| 玩家初始HP | 240 |
| 基础牌每费伤害 | 基础4 / 普通锚点6（单张16/24，能耗4） |
| 普通敌人HP(1-3幕) | 96 / 192 / 384 |
| Boss HP(1-3幕) | 720 / 960 / **1440**(最终Boss) |
| 1-4幕敌人伤害倍率 | 1.0 / 1.2 / 1.5 / 2.0 |

> 注：敌人复用玩家牌时，牌的**基础数值不变**（打击16伤/劈砍24伤），但敌人的 HP/回能可调，形成差异。

### 【噬血君王】The Blood King（3幕最终Boss，阶段切换）
| 字段 | 值 |
|------|----|
| 类型 | Boss（阶段切换） |
| 出现幕 | 3（幕末·最终Boss） |
| HP | 1440 |
| 回能速率 | 9/s（略快于基准8） |

**阶段1「鲜血循环」（9张，预设顺序）：**
1. **【专属】血刃**（能耗4，24伤+8层流血）
2. 劈砍（能耗4，24伤）
3. 撕裂（能耗4，3×8伤+12层流血）
4. 格挡（能耗4，20甲）
5. 双击（能耗4，12+12伤）
6. 劈砍（能耗4，24伤）
7. **【专属】血刃**（能耗4，24伤+8层流血）
8. **【专属】血爆**（能耗12，穿刺48伤+消耗敌人所有流血层数，每层1点真实伤害）
9. 格挡（能耗4，20甲）

**循环节奏：**
- 单循环时长：约4.9s逻辑（8×0.44 + 1×1.33，回能9）
- 单循环伤害：即时192 + 流血触发约104 + 血爆收割约28（玩家流血层峰值≈28）
- 打法风格：叠层→收割循环。每循环叠玩家流血28层，循环末【血爆】一次清空（穿刺48+层数真伤≈76），把"永久悬顶"变成"可预判的单次爆发"。

**设计意图：** 阶段1，主题"流血循环"。流血层数与血爆伤害的因果链**玩家可见**（策略前置）——层数越高血爆越痛，逼玩家在收割前加速输出。克制护甲流（流血/穿刺均为真伤），玩家应对：高DPS速杀、吸血续航、荆棘反伤（高频攻击）。

**阶段2「猩红狂暴」（8张，HP首次≤50%触发切换，预设顺序）：**
1. 识破（能耗4，施加3层易伤）
2. 撕裂（能耗4，3×8伤+12层流血）
3. 虚弱术（能耗4，施加3层虚弱）
4. 双击（能耗4，12+12伤）
5. 劈砍（能耗4，24伤）
6. **【专属】血爆**（能耗12，穿刺48伤+收割）
7. 格挡（能耗4，20甲）
8. **【专属】猩红之矛**（能耗12，穿刺96伤；若敌人处于易伤，伤害×1.5=144）

**循环节奏：**
- 单循环时长：约5.3s逻辑（6×0.44 + 2×1.33，回能9）
- 单循环伤害：即时168~216 + 血爆收割约58（叠层放缓至12层/循环）
- 打法风格：混合爆发。易伤窗口（3s）内的【猩红之矛】144真伤是核心威胁，配合虚弱削玩家输出、血爆收割残留流血。

**设计意图：** 阶段2，主题"混合爆发"。从"滚雪球"转为"爆发窗口"：易伤×穿刺大招制造峰值，玩家须在两次大招间隔内结束战斗（剩余720HP，需 ~7s 内 ~100DPS）。阶段切换规则见《敌人设计规范》§四。

**应对思路：** 全程高输出速杀为主；阶段1 关注流血层数（血爆前调整护甲/吸血）；阶段2 易伤不可清除，大招前保持 HP 安全线；虚弱/荆棘/吸血均可生效。
