# 战斗设计规范

> 定义「即时制、全自动、1v1 对称卡牌对撞」战斗的设计原则、约束与禁区。
> 具体机制见 [核心战斗机制](../02_机制/核心战斗机制.md)。

---

## 设计目标

- **策略前置，系统执行**：所有玩家决策发生在战前（卡组构筑 + 排序），战斗完全交给系统自动播放
- **构筑即玩法**：核心乐趣来自 STS 式的卡组构筑深度（加卡/删卡/遗物/流派），而非战中操作
- **观战也要好看**：即便全自动，战斗播放过程也要有节奏感、可读性、爽快感
- **确定性**：相同输入可复现整场战斗，便于调试、平衡与回放

---

## 一、自动化的边界（第一性原则）

| 类别 | 是否允许 | 说明 |
|------|----------|------|
| 战前卡组排序 | ✅ **核心玩法** | 玩家在非战斗时手动排列抽牌堆顺序，这是主要的策略表达 |
| 战前卡组构筑 | ✅ **核心玩法** | 通过 STS 式加卡/删卡/遗物调整牌组 |
| 加速 / 减速 | ✅ 允许 | 观战体验刚需，仅调播放速率，不改变逻辑 |
| 暂停 | ✅ 允许 | 便于观察，不影响逻辑 |
| 战中调整顺序 | 🚫 禁止 | 进入战斗后顺序锁定 |
| 大招手动释放 | 🚫 禁止 | 无手动技能，纯自动出牌 |
| 走位 / 移动 | 🚫 禁止 | 无空间走位概念（1v1，无战场位置） |
| 目标手动指定 | 🚫 不适用 | 1v1 下目标唯一确定 |

### 禁区
- 🚫 任何要求玩家在战斗中操作的机制（破坏"纯挂机"定位）
- 🚫 必须手动操作才能通关的设计
- 🚫 引入空间/走位元素（与 1v1 对称卡牌对撞定位冲突）

---

## 二、对称性原则

- **规则对等**：玩家与敌人共享同一套战斗机制（抽牌堆/弃牌堆/洗牌/回能/自动出牌）
- **差异只来自配置**：敌人 = 不同的卡组 + 不同的回能参数，而非不同的规则
- **设计意义**：战斗本质是"两条出牌时间轴的对撞"，保证公平性与可读性

---

## 三、确定性原则

- 逻辑固定步长（60 tick/s），渲染帧率与逻辑分离
- 所有随机（洗牌等）用种子驱动的 PRNG，按 tick 顺序消耗
- 相同卡组顺序 + 相同回能参数 + 相同洗牌种子 = 可复现结果
- 这是为了：调试可复现、平衡可量化、回放可生成

---

## 四、即时制原则

"即时制"的体感来源不是操作，而是：
- **能量实时恢复**：能耗 = 出牌的时间成本
- **双方完全并行**：各自独立回能、可同时出牌，无回合/行动权交替
- **节奏感**：通过回能速率 × 能耗分布，让不同卡组打出不同的"播放节奏"

---

## 五、可读性与爽快感约束

| 约束 | 说明 |
|------|------|
| 出牌清晰可见 | 当前双方正在打出/即将打出的牌需有明确视觉指示 |
| 伤害数字 | 必须飘字，特殊效果有差异化表现 |
| 节奏张弛 | 不能全程高压或全程平淡，需通过卡组节奏制造起伏 |
| 结果可理解 | 玩家观战后应能理解"为什么赢/为什么输"（便于学习构筑） |
