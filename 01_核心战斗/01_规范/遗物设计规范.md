# 遗物设计规范

> STS 式"规则篡改型被动"。流派核心。
> ★ 池规模：精简(20-30件)，每件都强且独特。携带数量不限。
> ★ 设计重点：篡改**即时制特有轴**（回能/洗牌/DoT三系/出牌频率/Block时长），而非照搬 STS 回合制遗物。

---

## 设计目标

- 提供流派成型核心（每个遗物指向一种打法）
- 篡改底层规则，创造 STS 回合制做不到的即时制体验
- 与已定机制（能耗=时间/DoT三系/状态体系）深度结合

---

## 一、★ 遗物可篡改的轴（弹药库）

> 设计遗物时从下表选"篡改哪个轴"。重点利用**即时制独有维度**。

| 轴 | STS | 即时制独有玩法 |
|----|-----|---------------|
| **回能速率** | 无 | 永久改回能 = 改出牌节奏（快流派/慢流派） |
| 能耗 | 有 | 降低特定类型卡能耗（等效加速） |
| **洗牌/循环** | 无 | 改洗牌规则 = 改循环节奏（首轮延长/减少洗牌损耗） |
| **出牌频率** | 无 | 同帧连出加成 / 高频奖励 |
| **DoT 三系** | 单一毒 | 毒/灼烧/流血各有强化方向（永久不掉层/触发掉层/受击触发） |
| **Block 时长** | 回合清空 | 改5s衰减（延长/不掉/转永久） |
| 力量/敏捷 | 有 | 起始层数 / 触发额外效果 |
| HP | 有 | 最大HP / 回复 / 吸血 |
| 能量上限 | 无 | 我们能量无上限，但遗物可"开局送能量" |

## 二、遗物分类

| 类型 | 定位 | 例子 |
|------|------|------|
| **流派核心** | 定义一种打法，质变 | 毒伤翻倍 / 流血层数翻倍 / 护甲永久 |
| **数值加成** | 稳定强化 | 力量护符4层力量 / 生命之心+60最大HP / 迅捷回能+4/s |
| **机制篡改** | 改变规则运作 | 首轮抽牌堆+1轮不洗 / Block衰减×2时长 |
| **资源/经济** | 非战斗收益 | 商店折扣 / 战斗额外金币 |

## 三、★ 设计原则

### 3.1 乘区独立，避免无限叠加
- 遗物效果尽量作用于**不同的轴**（如一个加回能、一个加伤害、一个加DoT），避免多个遗物作用于同一乘区导致指数爆炸。
- 加法型（+N）可叠加；乘法型（×N）慎用，或限制数量。

### 3.2 即时制适配——禁用回合制绑定效果
| 禁用 | 理由 |
|------|------|
| "回合开始/结束"触发 | 无回合 |
| "抽牌"相关（除非映射为回能） | 无手牌/回合抽牌 |
| "保留/虚无"相关 | 无手牌概念 |

### 3.3 流派指向清晰
- 每件遗物应让玩家"看到它就知道该往哪流派走"
- 核心遗物配合特定卡组才能发挥，避免"万金油过强"

### 3.4 携带不限的平衡
- 因为不限携带，遗物间组合可能很强。接受这种"组合爽感"，但通过"乘区独立"控制不失控。
- 不设计"获得越多越强"的自我叠加遗物（如"每有1个遗物+X"）。
