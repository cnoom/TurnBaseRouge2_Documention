# 敌人设计规范

> 本文件定义敌人引擎规则、参数体系和意图系统。敌人配置数据见《敌人配置数据/》子目录。

## 敌人引擎规则

| 规则 | 说明 |
|------|------|
| 引擎类型 | 杀戮尖塔式意图系统，非卡组引擎 |
| 意图展示 | 玩家回合开始时展示敌人下回合意图，玩家可据此制定策略 |
| 行为模式 | 首轮动作列表 + 后续循环动作列表，后续为空则循环首轮 |
| 执行频率 | 每个敌人每回合执行一个动作，该动作可包含多个效果 |
| 效果复用 | 敌人动作的效果直接复用玩家卡牌的效果体系，一套效果系统服务两套逻辑 |
| 多敌人支持 | 1vN 架构，多敌人按速度降序依次行动 |

## 敌人参数说明

| 参数 | 说明 |
|------|------|
| HP | 生命值 |
| 速度 | 决定多敌人回合中的行动顺序，越高越先行动 |
| 行动力 | 每回合刷新的行动力上限 |
| 能量 | 每回合增加的能量值（跨回合累积） |
| 动作模式 | 首轮+后续循环的动作列表 |

## 意图类型

| 意图类型 | 说明 | UI 图标 |
|----------|------|---------|
| 攻击 | 显示伤害数值 | 攻击图标 |
| 防御 | 显示护盾数值 | 防御图标 |
| 增益 | 显示增益数值（力量、治疗等） | 增益图标 |
| 减益 | 显示减益数值（状态异常等） | 减益图标 |

## 轮转规则

- 战斗顺序：玩家回合 → 敌方回合（多敌人按速度降序依次行动） → 循环
- 玩家默认先手
- 战斗开始时，所有存活敌人生成首回合意图并展示
- 敌人回合结束时，推进动作指针并生成下一意图展示
- 眩晕状态下的敌人跳过行动，但意图指针不推进

## 效果与意图信息的关联

每种效果类型可返回对应的意图信息：

| 效果类型 | 意图类型 | 数值来源 |
|----------|----------|----------|
| 基础伤害 | 攻击 | 伤害值 |
| 穿刺伤害 | 攻击 | 伤害值 |
| 基础护盾 | 防御 | 护盾值 |
| 施加状态 | 减益 | 层数 |
| 治疗 | 增益 | 治疗量 |
| 属性修正 | - | -（未实现） |

## 敌人回合执行流程

```
敌人回合阶段入口
  │
  ├── 按速度降序排列存活敌人
  ├── 遍历每个敌人执行以下流程
  │     │
  │     ├── 1. 回合开始结算（护盾衰减、中毒、再生、眩晕判定等）→ 见《核心战斗机制》状态结算顺序
  │     ├── 2. 回合开始被动触发
  │     ├── 3. 若眩晕 → 跳过行动阶段（4,5）；回合结束效果（7,8）照常结算
  │     ├── 4. 执行当前意图动作效果
  │     │     ├── 发布出牌动画事件
  │     │     ├── 遍历效果 → 解析目标 → 执行
  │     │     └── 收集并发布动画事件（伤害/治疗/属性变化）
  │     ├── 5. 卡牌打出被动触发
  │     ├── 6. 出牌后状态触发（流血等，眩晕跳过则无触发）→ 见《核心战斗机制》阶段B
  │     ├── 7. 回合结束状态结算 → 见《核心战斗机制》阶段C
  │     ├── 8. 回合结束被动触发
  │     ├── 9. 推进动作指针 + 生成下一意图 → 展示
  │     └── 10. 死亡检测
  │
  └── 当前敌人完成 → 检查战斗是否结束 → 下一个敌人
```

## 数值校验标准

以下为**第一幕基准值**。敌人HP和伤害随幕阶梯增长。

| 敌人类型 | 目标伤害/回合 | HP范围 | 战斗时长 |
|----------|-------------|--------|----------|
| 普通敌人 | ~9 | 35-55 | 3-5回合 |
| 精英敌人 | ~14 | 100-120 | 6-8回合 |
| Boss | ~16 | 180 | 10-14回合 |

> 伤害/回合为原始输出，不含玩家护盾减免。实际HP损失约为此值的50-60%。
> 幕间增长逻辑详见《幕间增长原则》《普通敌人增长曲线》《精英与Boss增长曲线》，Boss配置详见《幕末Boss》。

## 幕间进化机制

敌人随幕推进获得新动作和新技能，遵循以下原则：

- **阶梯替换**：每个敌人每幕独立配置一套数值，非系数缩放
- **动作进化**：后期幕敌人获得新技能，增加机制复杂度（如新攻击模式、被动效果、阶段切换）
- **数值增长**：HP激进增长（第四幕约×3.3），伤害温和增长（第四幕约×1.45）
- **速度恒定**：速度在各幕间不变，出手频率由AP/EN系统驱动

> 详见《幕间增长原则》《普通敌人增长曲线》《精英与Boss增长曲线》。
