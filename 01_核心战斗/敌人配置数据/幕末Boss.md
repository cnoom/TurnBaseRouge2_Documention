# 幕末Boss配置数据

> 本文档为四个幕末Boss的独立配置数据。幕间强度增长逻辑和玩家成长对照见《敌人幕间强度》。

---

## 一、第一幕Boss（第5层）：腐化树精

| 参数 | 值 |
|------|-----|
| ID | 201 |
| HP | 180 |
| 速度 | 0 |
| 类型 | 召唤+场地型 |
| 行动力 | 2 |
| 能量增加 | 3 |

### 设计意图

作为玩家遇到的第一个Boss，机制以召唤为主，考验玩家的AOE清场能力和回合规划。难度设计为"可感知压力但不至于团灭"。

### 动作模式

**阶段一（HP>50%）**

| 回合 | 动作 | 意图类型 | 效果 |
|------|------|----------|------|
| 1 | 根须缠绕 | 攻击+减益 | 8伤害+施加1层虚弱 |
| 2 | 腐化吐息 | 攻击 | 12伤害+施加2层中毒 |
| 3 | 播种 | 增益 | 召唤1只腐化幼苗（HP=25，2伤害/回合） |
| 4 | 根须缠绕 | 攻击+减益 | 8伤害+施加1层虚弱 |
| 5 | 荆棘之雨 | 攻击 | 4×3=12伤害（全体） |
| 6 | 腐化吐息 | 攻击 | 12伤害+施加2层中毒 |
| 7+ | 循环回合4-6 | | |

**阶段二（HP≤50%，仅触发一次）**
- 立即召唤2只腐化幼苗
- 所有腐化幼苗HP上限+5
- 自身获得2层荆棘

### 腐化幼苗

| 参数 | 值 |
|------|-----|
| HP | 25 |
| 伤害/回合 | 2 |
| 亡语 | 死亡时对玩家造成5伤害 |

> 幼苗不参与意图系统，固定每回合攻击。玩家需要权衡：先清幼苗还是集火Boss。

**阶段一（HP>50%）**

| 回合 | 动作 | 意图类型 | 效果 |
|------|------|----------|------|
| 1 | 暗影斩 | 攻击 | 15伤害 |
| 2 | 暗影护盾 | 防御 | 获得15护盾 |
| 3 | 暗影弹 | 攻击 | 10穿刺伤害 |
| 4 | 黑暗低语 | 减益 | 施加2层虚弱+1层易伤 |
| 5 | 暗影斩 | 攻击 | 15伤害 |
| 6 | 暗影爆发 | 攻击 | 22伤害（蓄力1回合后释放） |

**阶段二（HP≤50%，触发时清除所有负面状态）**

| 回合 | 动作 | 意图类型 | 效果 |

| 2 | 深渊凝视 | 减益 | 施加2层易伤+2层虚弱 |

| 速度 | 0 |

### 设计意图

冻结机制Boss，通过叠加冻结增加玩家能量消耗，同时周期性释放大范围爆发。考验玩家对能量管理和爆发窗口的把握。

### 动作模式

**阶段一（HP>50%）**

| 回合 | 动作 | 意图类型 | 效果 |
|------|------|----------|------|
| 1 | 冰霜吐息 | 攻击 | 12伤害+施加2层冻结 |
| 2 | 龙翼横扫 | 攻击 | 16伤害（全体） |
| 3 | 极寒领域 | 减益 | 施加3层冻结（全体） |
| 4 | 蓄力 | 增益 | 获得3层锐利 |
| 5 | 冰晶爆裂 | 攻击 | 8×3=24+锐利伤害 |
| 6 | 冰霜吐息 | 攻击 | 12伤害+施加2层冻结 |
| 7+ | 循环回合2-5 | | |

**阶段二（HP≤50%，触发时清除自身DOT）**

| 变化项 | 说明 |
|--------|------|
| 极寒领域 | 额外施加1层虚弱 |
| 冰晶爆裂 | 变为穿刺伤害 |
| 新增被动 | 每第5回合自动获得2层护盾(10) |

## 四、第四幕Boss/最终Boss（第20层）：混沌之源

| 参数 | 值 |
|------|-----|
| ID | 204 |
| HP | 500 |
| 速度 | 2 |
| 类型 | 全能型（三阶段） |
| 行动力 | 3 |
| 能量增加 | 4 |

### 设计意图

游戏的最终考验，三阶段机制分别验证构筑的生存、输出和综合能力。阶段一切换到阶段二时清除DOT防止流派歧视，阶段三进入狂暴模式给予最终压迫感。

### 动作模式

**阶段一：混沌风暴（HP>70%）**

| 回合 | 动作 | 意图类型 | 效果 |
|------|------|----------|------|
| 1 | 混沌射线 | 攻击 | 15穿刺伤害 |
| 2 | 元素混乱 | 减益 | 施加1层中毒+1层灼烧+1层流血 |
| 3 | 混沌风暴 | 攻击 | 6×3=18伤害（全体） |
| 4 | 能量汲取 | 攻击+增益 | 10伤害，自身回复15HP |
| 5+ | 循环 | | |

**阶段二：虚空形态（HP 30%-70%）**
- 进入时清除所有DOT状态
- 获得被动：每回合开始获得2护盾

| 回合 | 动作 | 意图类型 | 效果 |
|------|------|----------|------|
| 1 | 虚空斩 | 攻击 | 20伤害+施加1层易伤 |
| 2 | 虚空护盾 | 防御 | 获得20护盾+2层荆棘 |
| 3 | 虚空召唤 | 增益 | 召唤1只虚空碎片（HP=40，8穿刺伤害/回合） |
| 4 | 虚空湮灭 | 攻击 | 25穿刺伤害 |
| 5+ | 循环 | | |

**阶段三：终焉（HP≤30%）**
- 进入时获得3层力量+3层敏捷
- 场上所有虚空碎片强化（HP+20，伤害+4）

| 回合 | 动作 | 意图类型 | 效果 |
|------|------|----------|------|
| 1 | 终焉宣告 | 减益 | 施加3层易伤 |
| 2 | 终焉射线 | 攻击 | 30穿刺伤害 |
| 3 | 混沌新生 | 增益 | 召唤1只强化虚空碎片，回复20HP |
| 4 | 万物终结 | 攻击 | 40伤害（全体） |
| 5+ | 循环 | | |
