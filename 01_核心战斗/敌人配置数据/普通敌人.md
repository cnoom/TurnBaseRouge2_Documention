# 普通敌人

## 已配置

### N1 哥布林（ID=1）

**类型：** 速攻型
**敌人池：** 全幕出现（第一幕～第四幕）

> 低HP高输出的速攻型敌人。核心机制为嚎叫叠力量逐步增伤，后期幕新增乱击（多段+流血）和狂怒（残血反击）提高威胁。

---

#### 第一幕（第1-5层）

| 属性 | 值 |
|------|-----|
| HP | 45 |
| 速度 | 0 |

> **力量机制**：力量为全局被动，对**所有攻击动作**（抓击、投石、乱击）生效。每层力量使伤害+1。力量可叠加。

**动作模式（3回合一循环）：**

| 回合 | 动作 | 意图 | 基础效果 |
|------|------|------|----------|
| 1 | 抓击 | 攻击 | 8伤害 |
| 2 | 抓击 | 攻击 | 8伤害 |
| 3 | 投石 | 攻击 | 11伤害 |
| 4 | 嚎叫 | 增益 | 获得1层力量 |
| 5+ | 抓击 | 攻击 | 4伤害 |

**行为模式（力量0层起点）：**

```
回合1：抓击(8+0力量)        = 8伤害
回合2：抓击(8+0力量)        = 8伤害
回合3：投石(11+0力量)       = 11伤害
回合4：嚎叫 → 力量=1
回合5：抓击(4+1力量)        = 5伤害
回合6：抓击(8+1力量)        = 9伤害
回合7：投石(11+1力量)       = 12伤害
回合8：嚎叫 → 力量=2
回合9：抓击(4+2力量)        = 6伤害
...持续递增
```

首回合两次高伤害抓击形成压力。嚎叫每循环叠加1层力量，使所有攻击伤害持续递增。战斗越久威胁越大。

### N2 骷髅兵（ID=2）

**类型：** 攻防型
**敌人池：** 全幕出现（第一幕～第四幕）

> 攻防交替的稳健型敌人。核心机制为举盾护体+骨矛爆发，后期幕新增穿刺伤害、碎骨（易伤）和亡语（死亡反噬），考验玩家护盾预判和击杀时机。

---

#### 第一幕（第1-5层）

| 属性 | 值 |
|------|-----|
| HP | 50 |
| 速度 | 0 |

**动作模式（4回合一循环）：**

| 回合 | 动作 | 意图 | 效果 |
|------|------|------|------|
| 1 | 骨击 | 攻击 | 5伤害 |
| 2 | 举盾 | 防御 | 获得6护盾 |
| 3 | 骨击 | 攻击 | 5伤害 |
| 4 | 骨击 | 攻击 | 8伤害 |
| 5 | 举盾 | 防御 | 获得6护盾 |
| 6 | 骨矛 | 攻击 | 12伤害（爆发） |

**行为模式：**

```
回合1：骨击5               = 5伤害
回合2：举盾6盾             = 6护盾
回合3：骨击5               = 5伤害
回合4：骨击8               = 8伤害
回合5：举盾6盾             = 6护盾
回合6：骨矛12              = 12爆发伤害
```

攻防交替，骨矛回合爆发。首轮温和让玩家建立节奏。玩家需预判骨矛回合准备护盾。
