# 关卡设计规范

> 定义地图关卡的结构原则、难度梯度与选项类型约束。

## 设计目标
- 每层向玩家展示明确的"奖励内容"与"预期敌人"，二者绑定
- 每层必有且仅有一个精英选项（高危版），对应更强的敌人和更好的奖励
- 玩家必须在战前评估自身构筑、洞察敌人机制，做出最优的战略决策
- 战斗为自动战斗，验证玩家的战前策略

## 核心规则

### 一、层结构
每层3个选项：第1个为固定选项，第2、3个为随机选项。
- **固定选项**：每层必定为"三选一卡牌"
- **随机选项**：从6类选项中根据当前层数所属的"四幕"权重随机抽取，2个选项互不重复

### 二、精英选项（高危版）
每层3个选项中，必有且仅有一个被指定为精英选项。该选项自动获得高危版强化效果，并绑定精英级敌人。其余两个为标准版。

### 三、第20层
固定为最终Boss战，无选项。

## 选项类型

| 选项类型 | 说明 |
|----------|------|
| 三选一卡牌 | 从3张随机卡牌中挑选1张 |
| 删除卡牌 | 删除牌组中1张卡牌 |
| 商店 | 进入商店购买/删除 |
| 随机事件 | 触发随机事件 |
| 普通遗物 | 获得1件普通遗物 |
| 稀有遗物 | 获得1件稀有遗物 |

## 与其他系统的关联
- **依赖**：核心战斗机制（自动战斗）、卡牌设计（卡牌池）、敌人设计（敌人数据）、遗物系统（遗物池）
- **被依赖**：商店系统（商店选项）、事件系统（随机事件选项与事件池）、奖励系统（奖励生成）
