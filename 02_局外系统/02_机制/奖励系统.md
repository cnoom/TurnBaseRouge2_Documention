# 奖励系统

> 战斗/事件/宝箱的奖励产出规则。
> ★ 核心是 STS 式"三选一加卡"，是局内成长的主引擎。

---

## 设计目标

- 提供局内成长（加卡/金币/遗物）
- 奖励与敌人难度匹配（精英/Boss 给更好）
- 让"加卡"与"随时可排"配合（加卡不强制排序）

---

## 一、普通战斗奖励

| 奖励 | 说明 |
|------|------|
| **三选一加卡** | 战斗胜利后，从卡池抽 3 张（随机稀有度），选 1 张加入牌组 |
| 金币 | **25 £/场**（主力来源，约 15 场） |

### 三选一卡池
- 从《卡牌数据》普通/稀有/罕见中抽取（基础牌不在池）
- 稀有度权重：**普通 65% / 稀有 30% / 罕见 5%**
- 三张尽量**跨稀有度**，让玩家在"稳"与"赌"间选择

---

## 二、精英战斗奖励（更高）

| 套餐 | 说明 |
|------|------|
| 三选一加卡 | 稀有度权重上调：**普通 35% / 稀有 45% / 罕见 20%** |
| **遗物** | 精英必掉 1 件遗物（随机） |
| 金币 | **50 £/场**（风险补偿，约 3 场） |

> 精英的高风险由遗物+高稀有度+双倍金币补偿——这是 STS 式"精英值得打"的设计。

---

## 三、Boss 奖励（最高）

| 奖励 | 说明 |
|------|------|
| **罕见遗物** | Boss 必掉 1 件遗物（从罕见池） |
| 三选一加卡 | ★ **三张全罕见（罕见 100%）**——必给高质量流派牌 |
| 金币 | **60 £/场**（3 个 Boss） |
| （幕末）HP 回满 + 进入下一幕 | 见《地图与关卡设计》§四 |

---

## 四、宝箱奖励

- 无战斗，直接获得：遗物 或 卡 + 金币
- 稀有度较高（惊喜感）
- 贡献一局约 95 £ 浮动金币

---

## ★ 金币与稀有度数值总表（首版自洽框架）

> 锚点：以「删卡」为核心倒推。一局期望删 5 张（累计 575 £）→ 总收入 ~800 £ → 余约 225 £ 买卡/攒遗物。详见《数据字典》§六。

| 项 | 数值 |
|----|------|
| 普通战斗金币 | 25 £/场 |
| 精英战斗金币 | 50 £/场 |
| Boss 金币 | 60 £/场 |
| 一局总收入目标 | ~800 £ |
| 删卡递增 | 50/75/100/150/200/250+ £ |
| 普通战斗三选一权重 | 普65/稀30/罕5 |

> 精确校准待原型/模拟器；首版以"自洽"为目标（删卡为核心去向、各梯度合理）。

---

## 五、遗物系统（概览）

> 遗物是 STS 式"规则篡改型被动"，是流派核心。本节为概览，详见《遗物设计规范》《遗物数据》（首批 21 件）。

| 类型 | 例子 |
|------|------|
| 数值加成 | 力量护符（4层力量）/ 生命之心（+60最大HP）/ 迅捷（回能+4/s） |
| 规则篡改 | 永甲（护甲不衰减）/ 毒心（毒结算间隔减半）/ 法则（弃牌堆不洗牌） |
| 流派核心 | 战神（力量流）/ 血祭（流血+力量双乘）/ 余烬（灼烧转持续） |

> 遗物设计已配合全部已定机制（能耗=时间/DoT三系/状态体系等），后续扩充按《遗物设计规范》执行。

---

## 六、即时制适配：加卡不强制排序

- 战斗胜利 → 三选一 → 选定卡加入牌库
- **不弹出排序界面**（玩家选择"随时可排"）
- 玩家可在下一个节点自行整理顺序
