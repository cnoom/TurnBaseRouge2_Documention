# 地图与关卡设计

> STS 式节点图地图。3 幕结构，玩家选路推进。
> ★ 与 STS 的差异：即时制战斗时长波动大（2s~60s），故节点数/休息密度需重新权衡。

---

## 设计目标

- 提供探索感与风险选择（普通路 vs 精英路）
- 控制单局节奏（3幕 × 30~60分钟）
- 让"随时可排"的牌库管理融入推进流程

---

## 一、总体结构：3 幕

| 幕 | 节点层数 | 幕末 | 主题 |
|----|----------|------|------|
| 第1幕 | **13**层 | Boss（如腐朽之王） | 入门、教学、流派雏形 |
| 第2幕 | **15**层 | Boss（如烈焰魔王） | 流派成型、精英考验 |
| 第3幕 | **17**层 | 最终Boss（噬血君王） | 流派大成、深度对抗 |

> 幕间有**幕间休息**：幕末Boss战胜利后，**HP 回满**进入下一幕。STS 式。
> ★ HP 规则双层：**幕内**跨场保留（休息点恢复 30% 续航）；**幕间**Boss 胜利后回满（每幕一个完整挑战单元）。

### 单局时长校验
- 单场战斗平均 5-15s（逻辑）→ 含表现约 30-90s
- 路径上节点期望（按权重 45/20/12/10/8/5%）：战斗 ~19 场、事件 ~9 个、精英 ~5 场、休息 ~4 个、商店 ~3 个、宝箱 ~2 个
- 3 幕 ≈ 30-40 场交互，预估 30~60 分钟 ✓ 符合定位
- 金币锚点自洽：普通战斗 ~15-18 场×25£ + 精英 3-5 场×50£ + Boss 3×60£ + 事件/宝箱浮动 ≈ **800 £** ✓（玩家选路会避战部分战斗，取路径期望中值）

## 二、节点类型

| 节点 | 图标 | 说明 | 频率 |
|------|------|------|------|
| **普通战斗** | ● | 普通敌人，难度低，给基础奖励 | 最多 |
| **精英战斗** | ▲ | 精英敌人，难度高，给稀有奖励（遗物） | 较少，需选路 |
| **休息点** | ♨ | 恢复 HP（部分比例）或升级卡牌 | 每幕 1-2 个 |
| **商店** | $ | 花 £ 购买卡/遗物/删卡 | 每幕 1 个 |
| **事件** | ？ | 随机事件，有得有失 | 中等 |
| **宝箱** | ■ | 无战斗，直接获得遗物/卡 | 稀有 |
| **Boss** | ★ | 幕末，章节终结 | 每幕末 1 个 |

### 节点分布权重（单幕基准，待校准）

| 节点 | 占比 | 备注 |
|------|------|------|
| 普通战斗 | ~45% | 主力 |
| 事件 | ~20% | 变数 |
| 精英战斗 | ~12% | 高风险高回报 |
| 休息点 | ~10% | 续航 |
| 商店 | ~8% | 每幕保底1个 |
| 宝箱 | ~5% | 惊喜 |

> 精英路 vs 安全路：地图上精英节点周边常有更好奖励，引导玩家做风险决策。

## 三、路径规则（STS 式）

- 每层有 2-4 个节点，玩家从当前节点选**相邻下层节点**前进
- **不能回退**（Roguelike 铁律）
- 起点固定，终点为 Boss
- 路径有分叉与汇合，形成"选路"

```
        起点
       /    \
      ●      ▲(精英)
     / \    / \
    ●   ？  ●   $
     \ /    \ /
      ♨      ●
       \    /
        ...
        Boss
```

---

## 四、即时制适配：战斗时长波动的应对

> STS 战斗时长稳定，休息点可预测。即时制战斗时长波动大，需注意：

- **休息点恢复比例可调高**：即时制易出现"被滚雪球"（毒/快攻），恢复需够用
- **精英奖励更高**：精英风险大（可能重伤），遗物/卡奖励须值得
- **HP 携带跨场**：玩家 HP 在节点间**保留**（非每场回满），休息点恢复——这是 STS 式压力来源

### HP 跨场规则
- **幕内**：每场战斗后 HP **不回满**，保留当前值；休息点恢复 30% HP（见下）
- **幕间**：幕末 Boss 战胜利后 HP **回满**，进入下一幕（每幕一个完整挑战单元，跟 STS）
- 升级卡牌（休息点二选一）：放弃回血，换取强化一张卡（见 A5/休息点规则）

---

## 五、随时可排的融入

- 玩家在**任何非战斗节点**（含移动途中）可打开牌库调整排序
- 加卡（战斗/事件/商店获得）后不强制弹排序界面，玩家自行决定何时整理
- 战斗开始时，按牌库当前顺序作为首轮出牌序列

---

## 与其他系统的关联

- **依赖**：奖励系统（战斗后给什么）、商店系统、事件设计规范、敌人卡组（节点敌人配置）
- **被依赖**：进度与成长（地图推进=局内成长载体）
