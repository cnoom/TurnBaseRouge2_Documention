# 地图与关卡设计

> 地图采用"固定分层 + 三选一决策"结构，共20层战斗，第20层为最终Boss战。核心体验是"风险与回报的配对抉择"。

## 设计目标
- 每层向玩家展示明确的"奖励内容"与"预期敌人"，二者绑定
- 每层必有且仅有一个精英选项（高危版），对应更强的敌人和更好的奖励
- 玩家必须在战前评估自身构筑、洞察敌人机制，做出最优的战略决策
- 战斗为自动战斗，验证玩家的战前策略

## 与其他系统的关联
- **依赖**：核心战斗机制（自动战斗）、卡牌设计（卡牌池）、敌人设计（敌人数据）、遗物系统（遗物池）
- **被依赖**：商店系统（商店选项）、事件系统（随机事件选项）、奖励系统（奖励生成）

## 一、核心理念

地图采用"固定分层 + 三选一决策"结构，共20层战斗，第20层为最终Boss战。

核心体验是"风险与回报的配对抉择"：每一层向玩家展示明确的"奖励内容"与"预期敌人"，二者绑定。每层必有且仅有一个精英选项（高危版），对应更强的敌人和更好的奖励。玩家必须在战前评估自身构筑、洞察敌人机制，做出最优的战略决策。战斗为自动战斗，验证玩家的战前策略。

---

## 二、层结构与选项生成规则

### 2.1 基本结构

每层3个选项：第1个为固定选项，第2、3个为随机选项。

- **固定选项**：每层必定为"三选一卡牌"。第15层固定替换为"终极锻造炉"。
- **随机选项**：从6类选项中，根据当前层数所属的"四幕"权重随机抽取，2个选项互不重复。

### 2.2 精英选项（高危版）

每层3个选项中，必有且仅有一个被指定为精英选项。该选项自动获得高危版强化效果（从对应强化池中等概率随机抽取），并绑定精英级敌人。其余两个选项为标准版（标准奖励，常规敌人）。

### 2.3 第20层

固定为最终Boss战，无选项。

## 三、选项类型池与风险回报规则

| | 标准版 | 高危版（精英选项） |
|---|---|---|
| **规则** | 基础奖励，对应常规敌人 | 统一对应精英级敌人。奖励为"基础奖励 + 从强化池随机抽取的一个效果" |

### 选项类型一览

| 选项类型 | 标准版 | 高危版强化效果池（等概率） |
|---|---|---|
| **三选一卡牌** | 从当前层级卡牌池随机3张，选1张 | ① 1张来自更高一级稀有度池 ② 可以刷新一次展示的卡牌 ③ 稀有卡牌的出现概率+5% |
| **删除卡牌** | 花费金币删除1张手牌 | ① 免费删除1张 ② 额外删除一张（付费） ③ 随机删除3张（付费） |
| **商店** | 商品原价出售 | ① 全场九折 ② 可以刷新一次商店 ③ 第一件购买的物品半价 |
| **随机事件** | 从标准事件池抽取 | ① 事件成功率+10% ② 免除选项负面效果 ③ 只会随机到正面事件 |
| **普通遗物** | 随机获得1个普通遗物 | ① 二选一 ② 奖励可刷新2次 |
| **稀有遗物** | 随机获得1个稀有遗物 | ① 二选一 ② 奖励可刷新2次 |

## 四、各选项规则详解

### 4.1 三选一卡牌

**标准版**：展示当前层级卡牌池中随机3张，玩家选择1张加入牌组。

**高危版强化效果**：

| 编号 | 效果 | 说明 |
|---|---|---|
| ① | 升稀有度 | 其中1张必定来自更高一级稀有度池 |
| ② | 刷新 | 玩家可以刷新一次展示的3张卡牌，在刷新前后的两组卡牌中任选其一 |
| ③ | 稀有概率+5% | 生成每张卡牌时，出现稀有及以上品质的概率额外增加5% |

### 4.2 删除卡牌

**标准版费用表**：

| 删除次数 | 第1次 | 第2次 | 第3次 | 第4次 | 第5次及以上 |
|---|---|---|---|---|---|
| 花费金币 | 75 | 100 | 125 | 150 | 200 |

**标准版**：支付当前次数对应的金币，手动选择1张手牌删除，累计次数+1。

**高危版强化效果**：

| 编号 | 效果 | 说明 |
|---|---|---|
| ① | 免费删除1张 | 不消耗金币，不累计次数，手动选择1张手牌删除 |
| ② | 额外删除一张（付费） | 先按标准流程付费删1张（次数+1），再获得一次额外删牌机会，同样按当前次数付费再删1张（次数再+1）。两次均可手动选择目标 |
| ③ | 随机删除3张（付费） | 支付一次当前次数对应的金币（次数+1），系统从牌组中随机选择3张删除。玩家不可选择具体删除哪张 |

### 4.3 商店

**标准版**：进入商店，所有商品原价出售。

**高危版强化效果**：

| 编号 | 效果 | 说明 |
|---|---|---|
| ① | 全场九折 | 所有商品打九折 |
| ② | 刷新商店 | 可以刷新一次商店商品，在刷新前后的两组商品中任选其一购买 |
| ③ | 首件半价 | 第一件购买的物品半价，其余原价 |

### 4.4 随机事件

**标准版**：从标准事件池中随机触发一个事件，事件内选项可能包含正面、负面或交易性质。

**高危版强化效果**：

| 编号 | 效果 | 说明 |
|---|---|---|
| ① | 成功率+10% | 事件中所有带概率判定的有利选项，成功率增加10%（如"30%概率获得遗物"变为"40%"）。负面概率不变 |
| ② | 免除负面效果 | 若事件中某个正面奖励附带负面代价，选择后不触发该负面代价 |
| ③ | 只会随机到正面事件 | 该次事件必定从正面/有益事件子池中抽取，不会出现纯负面事件 |

### 4.5 普通遗物

**标准版**：随机获得1个普通遗物。

**高危版强化效果**：

| 编号 | 效果 | 说明 |
|---|---|---|
| ① | 二选一 | 展示2个普通遗物，玩家选择1个 |
| ② | 奖励可刷新2次 | 每次展示1个普通遗物，玩家可刷新（最多2次），从所有展示过的遗物中选择1个 |

### 4.6 稀有遗物

**标准版**：随机获得1个稀有遗物。

**高危版强化效果**：

| 编号 | 效果 | 说明 |
|---|---|---|
| ① | 二选一 | 展示2个稀有遗物，玩家选择1个 |
| ② | 奖励可刷新2次 | 每次展示1个稀有遗物，玩家可刷新（最多2次），从所有展示过的遗物中选择1个 |

## 五、敌人预览信息

每个选项节点展示以下信息：

1. **选项名称与图标**
2. **难度标识**：精英选项有骷髅图标和特殊颜色标识
3. **奖励预览**：标准版显示基础描述；精英选项显示随机抽中的具体强化效果
4. **敌人预览**：敌人名称 + 核心机制关键词

### 敌人预览示例

| 类型 | 示例 |
|---|---|
| 标准敌人 | 巡逻守卫，特性：反击 |
| 精英敌人（精英选项） | 精英·巡逻队长，特性：激怒、反击 |

## 六、名词解释

| 术语 | 说明 |
|---|---|
| 刷新 | 重新随机生成当前展示的内容，玩家可在刷新前后的结果中任选其一 |
| 免除负面效果 | 选择带负面代价的正面奖励时，不触发该负面代价 |
| 正面事件 | 对玩家有利、无纯负面结果的事件，可能包含明确交易 |
| 稀有概率+5% | 生成每张卡牌时，出现稀有及以上品质的概率额外增加5% |
| 精英级敌人 | 所有精英选项统一对应的敌人难度等级，强度高于常规敌人 |
| 精英选项 | 每层必有且仅有一个的高危版选项，绑定精英级敌人和强化奖励 |

## 七、玩家决策流程总结

1. **观察**：每层进入时，查看三个选项。其中必有一个带骷髅标识的精英选项，另外两个为标准选项。
2. **评估**：
   - 精英选项的强化效果是什么？
   - 精英选项对应的精英敌人，我的卡组能打过吗？
   - 如果跳过精英选项，两个标准选项中哪一个更适合我？
3. **选择**：选择最适合当前构筑和长期规划的选项。
4. **战斗**：进入自动战斗，验证策略。
5. **结算**：获得奖励，进入下一层。
