# 术语表

> 统一项目中使用的术语定义，消除歧义。

## 资源类

| 术语 | 缩写 | 定义 |
|------|------|------|
| 行动力 | AP | 控制单回合出牌频次的资源，每回合刷新至上限，不跨回合保留 |
| 能量 | EN | 控制高阶卡牌爆发周期的资源，每回合定量累加，跨回合保留 |

## 战斗流程类

| 术语 | 定义 |
|------|------|
| 当前牌 | 场上始终唯一存在的那张待判定卡牌 |
| 抽牌堆 | 尚未被抽取的卡牌集合 |
| 弃牌堆 | 已被打出的卡牌集合（非消耗牌） |
| 消耗堆 | 被[消耗]标签移出战斗的卡牌集合 |
| 强制断档 | 当前牌费用不满足时，回合立刻结束 |
| 首轮顺序段 | 战斗第一轮循环，按战前设定顺序打出 |
| 后续随机段 | 首轮之后，洗牌后随机抽取 |
| 出牌引擎 | 自动判定→打出→抽牌→再判定的循环机制 |

## 卡牌类

| 术语 | 定义 |
|------|------|
| [消耗] | 卡牌标签，打出后永久移出本场战斗 |
| [固有] | 卡牌标签，洗牌后必定处于牌堆顶部第一张（多个固有牌在固有中随机排序，但都位于非固有牌之前） |
| [虚无] | 卡牌标签，打出后本局不可再获取 |
| 跳过牌 | 卡牌效果触发"跳过下一张牌"：下一张被抽到的牌直接弃置，不判定费用也不执行效果 |

## 属性修正类

| 术语 | 定义 |
|------|------|
| 力量 | 每点+1造成的伤害，战斗内永久，不衰减，可无限叠加（含负值） |
| 敏捷 | 每点+1获得的护盾，战斗内永久，不衰减，可无限叠加（含负值） |

## 状态异常类

| 术语 | 类型 | 定义 |
|------|------|------|
| 易伤 | 异常·乘区 | 受到伤害×1.5，多层延长持续而非增强，每回合-1层 |
| 虚弱 | 异常·乘区 | 造成伤害×0.75，多层延长持续而非增强，每回合-1层 |
| 中毒 | 异常·持续伤害 | 回合开始扣（层数）点血，触发后-1层 |
| 灼烧 | 异常·持续伤害 | 回合结束扣（层数×2）点血，触发后-1层 |
| 流血 | 异常·持续伤害 | 敌方每次出牌时扣（层数）点血，触发后-1层 |
| 眩晕 | 异常·控制 | 跳过回合行动阶段（回合开始/结束效果照常结算），可多层，每跳过1回合-1层 |
| 冻结 | 异常·控制 | 抽到牌时EN消耗+max(1,层数×20%)，触发后减少对应层数，增加部分仅当前回合 |

## 增益状态类

| 术语 | 类型 | 定义 |
|------|------|------|
| 荆棘 | 增益·反击 | 受到攻击后反弹（层数×1）点伤害，触发后-1层 |
| 再生 | 增益·回复 | 回合开始回复（层数）点生命值，触发后-1层（中毒之后结算） |
| 锐利 | 增益·蓄力 | 可叠加，下次攻击牌伤害增加（全部层数）点，攻击时全部消耗 |

## 废卡类

| 术语 | 定义 |
|------|------|
| 废卡 | 特殊负面卡牌，被特定效果洗入抽牌堆，默认[消耗]（打出即移出） |
| 淤塞 | 1/0 [消耗]，无效果，白白消耗1AP |
| 腐蚀 | 0/1 [消耗]，无效果，白白消耗1EN |
| 伤痛 | 待定 [消耗]，对自己造成6点伤害，增加资源消耗（具体待定） |

## 卡牌类型类

| 术语 | 定义 |
|------|------|
| 攻击牌 | 造成伤害为主，可附带状态效果，伤害数值参照伤害锚点 |
| 技能牌 | 一次性效果（获得护盾、挂异常、治疗、获得属性等） |
| 能力牌 | 打出后建立本场战斗持续的触发规则（类似打出才生效的遗物），AP消耗2~3，打出后本场战斗消失（不进入任何牌堆，不可再次抽取） |

## 敌人类

| 术语 | 定义 |
|------|------|
| 普通敌人 | 基础战斗对手，具体 HP/伤害范围见《数据字典·六、敌人参数》 |
| 精英敌人 | 高威胁对手，具体 HP/伤害范围见《数据字典·六、敌人参数》 |
| Boss | 最强对手，具体 HP/伤害范围见《数据字典·六、敌人参数》 |
| 敌人意图系统 | 杀戮尖塔式意图系统，非卡组引擎，每回合执行一个预定义动作 |

## 防御类

| 术语 | 类型 | 定义 |
|------|------|------|
| 护盾 | 防御 | 伤害吸收层，每回合开始衰减30%（floor取整），衰减至0即消失 |

## 系统类

| 术语 | 定义 |
|------|------|
| 遗物 | 篡改底层规则的局内获取物，长线策略深度的载体，单局获取不跨局保留 |
| 普通遗物 | 小幅规则修改，适配性广，商店/普通战斗/事件获取 |
| 稀有遗物 | 显著规则修改，明确流派指向，精英/Boss/特殊事件获取 |
| 引擎稳定性 | 卡组在随机段不产生断档的能力 |
| 资源曲线 | AP与EN在多回合内的消耗与积累模式 |
