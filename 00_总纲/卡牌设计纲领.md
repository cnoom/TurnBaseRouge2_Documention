# 卡牌设计纲领

> 本文档是 2026-07-26「卡牌重做」决策后所有卡牌/流派设计的**统一纲领**。
> 旧版卡牌设计见《归档/2026-07-26_卡牌重做前/》。本文档取代旧版《卡牌设计规范》《卡组构筑规范》中的设计理念部分。
> 核心机制（双轨资源、断档、状态体系、出牌流程等）见《核心战斗机制》《状态体系》，本文档不重复。

---

## 一、设计目标

本次重做针对旧版卡牌的三大核心痛点：

| 痛点 | 旧版表现 | 本次解决思路 |
|------|---------|-------------|
| **流派联动弱** | 卡牌之间 combo 感不强，DOT/流血/消耗等流派缺乏引擎闭环 | 引入「联动维度覆盖」约束，每个流派必须明确覆盖 ≥3 个联动维度 |
| **主题感缺失** | 卡牌名字零散（打击/重击/穿刺…），缺乏统一叙事 | 卡通西幻主题 + 角色身份驱动命名，卡牌服务于角色故事 |
| **敌人/遗物配套不足** | 卡牌与敌人机制、遗物流派缺乏针对性校验 | 卡牌设计同步考虑敌人反制手段与遗物加成，标注校验关系 |

### 不做的事

- ❌ **不再维护数值锚点表**：旧版「EN=2→13伤害」这类硬锚点废弃。伤害/护盾数值由卡牌效果直接定义，按流派平衡而非全局锚点。
- ❌ **不重构核心机制**：双轨资源（AP/EN）、断档、护盾衰减、状态体系等底层规则封闭不变。
- ❌ **不一次性铺满全部内容**：先做 1 个角色跑通流程，验证后扩展。

## 二、卡池架构

采用**角色专属 + 通用**双层卡池：

```
┌─────────────────────────────────────────────┐
│  角色专属卡池（如：巴纳比专属）              │
│  - 初始卡组（10张，角色定档）                │
│  - 专属卡（~15张，仅该角色可获取）           │
│  - 专属遗物（2-3件，仅该角色可获取）         │
└─────────────────────────────────────────────┘
                    ↓ 玩家选角后混入
┌─────────────────────────────────────────────┐
│  通用卡池（所有角色共享）                    │
│  - 通用卡（三选一/商店/事件掉落）            │
│  - 通用遗物（地图/Boss/商店获取）            │
└─────────────────────────────────────────────┘
```

### 获取规则

| 来源 | 卡牌类型 | 说明 |
|------|---------|------|
| 战斗三选一 | 通用卡 + 当前角色专属卡 | 角色专属卡仅在该角色局内出现 |
| 商店 | 通用卡 + 当前角色专属卡 | 同上 |
| Boss 结算 | 通用史诗卡 + 当前角色专属史诗卡 | 同上 |
| 事件 | 通用卡 + 当前角色专属卡 | 同上 |
| 初始卡组 | 角色专属 | 选角时确定，不可更换 |

> **跨角色不共享**：A 角色局内获得的专属卡，在 B 角色局内不会出现。这保证角色身份的纯粹性。

## 三、流派体系（混合制）

流派分两类：

| 类型 | 定义 | 联动策略 | 示例 |
|------|------|---------|------|
| **专属流派** | 由角色身份决定，核心卡牌来自角色专属池 | **强联动** | 巴纳比的重击流、壁垒流 |
| **通用流派** | 跨角色可选，核心卡牌来自通用池 | **机制型联动** | 消耗流（首个） |

### 首批流派清单

| 流派 | 类型 | 角色归属 | 状态 |
|------|------|---------|------|
| 重击流 | 专属 | 巴纳比 | 设计中 |
| 壁垒流 | 专属 | 巴纳比 | 设计中 |
| 消耗流 | 通用 | — | 设计中 |

> 后续角色（巫师、游侠等）将各自携带 1-2 个专属流派，通用流派池逐步扩展。

## 四、核心设计原则

### 原则1：联动维度覆盖约束

**每个流派必须明确覆盖以下 4 个联动维度中的至少 3 个**，并在流派身份卡中标注每张关键牌所属的维度：

| 维度 | 作用 | 典型机制 |
|------|------|---------|
| **① 建立** | 积累流派资源（层数/标记/属性/卡组厚度） | 攒锐利、叠力量、堆护盾、把牌送进消耗堆 |
| **② 触发** | 在出牌循环中持续触发流派效果 | 攻击牌消耗锐利爆发、受击荆棘反弹、每消耗一张+力量 |
| **③ 转化** | 把积累的优势兑现为新收益 | 锐利→伤害、护盾→荆棘层数、消耗堆牌→抽回手 |
| **④ 支撑** | 维持循环顺畅（抽牌/减费/回收/防断档） | 攒EN牌、护盾衰减控制、过牌找关键牌 |

**约束细则**：
- 维度可以自由组合，**不强制三段顺序**（允许"持续输出型"和"一击终结型"并存）
- 同一流派的卡牌应在不同维度间形成闭环，避免"伪联动"（仅数值叠加而无机制 combo）
- 维度标注作为设计 review 与平衡调整的统一语言

### 原则2：混合联动策略

按流派类型采用不同的联动强度：

| 流派类型 | 单卡强度 | 联动后强度 | 设计意图 |
|---------|---------|-----------|---------|
| **专属流派** | 偏弱（明显低于通用牌） | 大幅超越通用牌 | 强身份感，凑齐 combo 才是"这个角色" |
| **通用流派** | 与通用牌持平 | 略超越通用牌 | 单卡可单飞，避免非本流派角色抽到毒牌 |

**平衡校验**：专属卡的单卡强度可以低于通用牌 20-30%，但联动后必须超越通用牌锚点 30%+，否则身份感不足。

### 原则3：每张卡牌标注联动信息

每张流派相关卡牌的效果描述后，必须标注所属流派和联动维度，格式：

```
[流派名·维度编号]
```

**示例**：
> **致命一击** | 1/2 | 造成 X 伤害，消耗全部锐利层数，每层+3伤害 *[重击流·②触发]*

无流派归属的通用单卡（如基础攻击牌）不标注。

## 五、流派身份卡模板

每个流派定稿时，使用以下模板明确其联动结构：

```markdown
### 流派名：【XXX流】（专属/通用）

**身份定位：** 一句话描述这个流派的"爽点"与核心体验
**联动策略：** 强联动 / 机制型联动
**覆盖维度：** ①建立 ②触发 ③转化（举例，标注覆盖了哪几个）

**核心机制：**
- 关键资源：XXX（如锐利层数、护盾值、消耗堆牌数）
- 关键状态/标签：XXX

**关键卡牌联动链：**
- 卡A（①建立）→ 卡B（②触发）→ 卡C（③转化）
- 卡D（④支撑）维持循环

**反制/弱点：**
- 怕 XXX 敌人/机制
- 怕 XXX 状态

**配套遗物：**
- 专属遗物 XXX：[篡改维度]
- 通用遗物 XXX：[篡改维度]

**敌人校验：**
- 设计目标敌人：XXX（用于验证流派上限）
- 反制敌人：XXX（用于验证流派弱点）
```

## 六、卡牌设计文档结构

未来每个角色的完整设计文档（如《菜鸟骑士巴纳比.md》）将按以下结构组织：

```markdown
# 角色名

## 一、角色档案
- 视觉设定、性格、身份故事

## 二、初始卡组（10张）
- 卡牌表

## 三、专属流派
### 流派1：XXX流（流派身份卡）
### 流派2：XXX流（流派身份卡）

## 四、专属卡池（~15张）
- 攻击牌 / 技能牌 / 能力牌
- 每张标注所属流派+联动维度

## 五、专属遗物（2-3件）
- 每件标注篡改维度+联动流派

## 六、与通用池的协同
- 哪些通用卡/遗物与本角色流派联动

## 七、敌人校验清单
- 本角色应能应对哪些敌人
- 本角色的弱点敌人
```

## 七、与其他系统的关联

| 关联系统 | 关系 | 说明 |
|----------|------|------|
| 核心战斗机制 | 上游 | 卡牌效果必须符合双轨资源、断档、状态体系等规则 |

| 局外系统 | 下游 | 三选一/商店/事件需按卡池架构区分专属/通用 |
