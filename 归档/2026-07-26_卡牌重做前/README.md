# 归档：2026-07-26 卡牌重做前

> 本目录保存「卡牌重做」决策前的旧版设计文档，作为历史参考。新设计稳定后这些文档不再维护，但保留以供比对。

## 归档原因

2026-07-26 决定**推倒重来**重新设计卡牌系统，主要动机：

1. **流派联动弱**：旧版卡牌之间 combo 感不强，DOT/流血/消耗等流派缺乏明确的引擎闭环
2. **主题感缺失**：卡牌名字零散（打击/重击/穿刺…），缺乏统一的世界观叙事和身份感
3. **敌人/遗物配套不足**：卡牌与敌人机制、遗物流派之间缺乏针对性校验关系
4. **稀有度失衡**：史诗偏高(22.2%)、普通偏低(41.7%)、AP=0/EN=0牌不足，分布偏离目标区间
5. **缺少角色系统**：旧版所有卡牌是通用池，没有角色身份概念
